### 3.3 工程与分发

- **无 AppIcon**（`App/` 下没有 Assets.xcassets）：装到机器上是默认网格图标。原版只有 57/114 px 图标，放大到 1024 会糊。
- **无 PrivacyInfo.xcprivacy**：用到 UserDefaults，上架校验会拦（侧载不受影响）。
- `UIRequiresFullScreen` 已被 iOS 26 弃用（CI 日志唯一一条 plist 告警）。保留是为了横屏保证，**暂不动**，等真机验证 iPad Slide Over 行为。
- 部署目标是 **26.0**，不是 27；"iOS 27" 目前只在文档里，CI 只认 Xcode 26。真矛盾是：若 runner 只剩 Xcode 27，第 2 步会红。

## 5. 接手时最容易踩的坑

- `shared_context/TASKS.md` 曾经只到 T-043，**别据此判断进度**；真实进度看 `progress/` 与 git 树。
- `git` 不在 PATH（在 `D:\tools\git\cmd`）；直连 github.com 不通，**只能走 API 推送**。
