## 设计说明（T-029）

按任务卡把 `WaveDirector` 从「每帧无条件抽一次」改为「选波→初始化批次→按 timer 出果」三段式：

1. **选波**（`selectNextWave`）：激活计数 +1 → 候选 `waveNo <= count && (count <= until || until == -2)` → 候选波 `currentChance = min(maxChance, currentChance + regrowth)`（maxChance 取该波 `chance`，加载器已继承 90）→ 多候选按 `currentChance*10` 权重、单候选直取 → 选中波 `currentChance = 0` → 初始化批次 → 写 `spawnFreeze/freezeRemaining`（`nextDelay/nextWait` 按 spInc 增量）。
2. **批次初始化**：数量按 `FUN_00057af0`：`trunc(min+minInc*spInc)` / `trunc(max+minInc*spInc)` 钳 ≥0；`high>low` 时 `rng.nextInt(high-low)+low`，否则 `low`；`remaining=total=count`；`timer=max(0, delay+delayInc*spInc)`；`kinds` 在此一次性解析（显式 fruit/bomb 保序，`.random` 按 `FruitInfo.chance` 累计权重抽一次，无候选返回空槽 -1 而非水果 0）。
3. **生成**：`spawnFreeze<=0` 时每 spawner 按 timer 递减逐个出果；每实体 `remaining -= 1`、`timer += max(0, delay+delayInc*spInc)`；bomb→`spawnBomb`、fruit→`spawnFruit`；生成时才置 `spawnFlag=1`。
4. **freeze 归零**：触发 `onFreeze` 后调用 `selectNextWave`（不再 `forceSpawn`）。
5. 删除 `Spawner.bombTriggerRemaining/fruitSpawnRemaining` 与 `SpawnTable` 在调度器内的使用；`forceSpawn` 移除。
6. `WaveSpawnBridge.triggerExplosion` 改名 `spawnBomb`（几何不动）。

`waitForEntities/waitForProcessing`、override 池、多玩家 freeze 驱动均标 [待验证]，原因写在文件头与具体位置。

    // MARK: WaveDirecting

    /// 每帧推进（§1.2 步骤 10 的子路径；分支链见 core_logic_notes §5.3）。
    public func tick(dt: Float, state: inout GameState, world: any EntityStore) {
        _ = state  // GameState 字段定义未在本卡注入；freeze 运行态暂存 WaveRuntime
        _ = world  // 世界生成走 spawnSink（避免扩展 EntityStore 过渡协议）

        guard dt > 0 else { return }
        guard runtime.spawnFreeze.count == playerCount else { return }

        // 步骤 1（步骤 3 的前置）：+0x17b = 0，本帧清零
        runtime.frameFlag = 0

        // 步骤 3：spawnFreeze 门控 → 生成循环
        for player in 0..<playerCount {
            if runtime.spawnFreeze[player] > 0 {
                runtime.spawnFreeze[player] = max(0, runtime.spawnFreeze[player] - dt)
                continue
            }
            runSpawnLoop(dt: dt, player: player)
        }

        // 步骤 4：freezeRemaining 递减，归零触发 OnFreeze → 选下一波
        tickFreezeRemaining(dt: dt)

        // 步骤 5：炸弹状态机 0 → 1 → 2
        tickBombStateMachine()
    }

    /// 由关卡逻辑触发冻结（外部设置 freezeRemaining）。
    /// 若该玩家已有冻结计时，则覆盖并重置「触发一次」标志。
    public func triggerFreeze(player: Int, duration: Float) {
        guard player >= 0, player < playerCount else { return }
        runtime.freezeRemaining[player] = max(0, duration)
        freezeTriggered[player] = false

    /// 波次选择（FUN_00054dd8 重建）[macho]。
    ///
    /// 规则（T-029 §5）：
    ///  1. 激活计数 +1；
    ///  2. 非首次选择时旧波 spInc +1；
    ///  3. 候选：`waveNo <= count` 且（`count <= until` 或 `until == -2`）；
    ///  4. 候选波 `chanceRegrowth > 0` 时 `currentChance = min(maxChance, currentChance + regrowth)`；
    ///  5. 多候选按 `currentChance * 10` 权重随机，单候选直取；
    ///  6. 选中波 `currentChance = 0`；重复 waveNo 合法（用数组下标区分）。
    ///
    /// [待验证] 全零权重时取文档顺序候选（原版分支未在导出文本中直接体现）。
    public func selectNextWave() {
        guard !waves.isEmpty else { return }

        // 1) 激活计数递增
        runtime.waveActivationCount += 1
        let count = runtime.waveActivationCount

        // 2) 非首次选择：旧波 spInc += 1
        if runtime.hasSelectedWave {
            runtime.currentWaveSpInc += 1
        }
        runtime.hasSelectedWave = true

        ensureChanceArray()

        // 3) 候选筛选
        var candidates: [Int] = []
        for (index, wave) in waves.enumerated() {
            guard wave.waveNo <= count else { continue }
            if wave.until == Constants.WaveDefaults.untilForever || count <= wave.until {
                candidates.append(index)
            }
        }
        guard !candidates.isEmpty else { return }

        // 4) currentChance 增长
        for index in candidates {
            let regrowth = waves[index].chanceRegrowth
            guard regrowth > 0 else { continue }
            let maxChance = waves[index].chance.map { Float($0) } ?? Self.fallbackWaveChance
            runtime.currentChances[index] = min(maxChance,
                                                runtime.currentChances[index] + regrowth)
        }

        // 5) 选中
        let chosen = pickCandidate(candidates)

        // 6) 选中后清零
        runtime.currentChances[chosen] = 0
        runtime.currentWaveIndex = chosen

        let wave = waves[chosen]

        // 7) 初始化每玩家每 spawner 批次
        initializeBatches(wave: wave, spInc: runtime.currentWaveSpInc)

        // 8) 设置 spawnFreeze / freezeRemaining（nextDelay / nextWait 及 inc/spInc）
        applyFreezeTimers(wave: wave, spInc: runtime.currentWaveSpInc)

        events?.onWaveStart(waveIndex: chosen, wave: wave)
    }

    // MARK: Private — selection

    private func pickCandidate(_ candidates: [Int]) -> Int {
        guard candidates.count > 1 else { return candidates[0] }

        var weights: [Int32] = []
        var total: Int32 = 0
        for index in candidates {
            let weight = truncToInt32(runtime.currentChances[index] * 10)
            weights.append(weight)
            total = total &+ weight
        }
        guard total > 0 else { return candidates[0] }

        let roll = rng.nextInt(total)
        var acc: Int32 = 0
        for (offset, weight) in weights.enumerated() {
            acc = acc &+ weight
            if roll < acc { return candidates[offset] }
        }
        return candidates[candidates.count - 1]
    }

    private func ensureChanceArray() {
        if runtime.currentChances.count != waves.count {
            var arr = runtime.currentChances
            if arr.count < waves.count {
                arr.append(contentsOf: [Float](repeating: 0, count: waves.count - arr.count))
            } else {
                arr.removeLast(arr.count - waves.count)
            }
            runtime.currentChances = arr
        }
    }

    private func applyFreezeTimers(wave: WaveInfo, spInc: Int32) {
        let inc = Float(spInc)
        let freeze = max(0, wave.nextDelay + wave.nextDelayInc * inc)
        let wait = max(0, wave.nextWait + wave.nextWaitSpInc * inc)
        for player in 0..<playerCount {
            runtime.spawnFreeze[player] = freeze
            runtime.freezeRemaining[player] = wait
            freezeTriggered[player] = false
        }
    }

    // MARK: Private — batch init

    private func initializeBatches(wave: WaveInfo, spInc: Int32) {
        var perPlayer: [[SpawnBatch]] = []
        perPlayer.reserveCapacity(playerCount)
        for _ in 0..<playerCount {
            var batches: [SpawnBatch] = []
            batches.reserveCapacity(wave.spawners.count)
            for spawner in wave.spawners {
                batches.append(makeBatch(spawner: spawner, spInc: spInc))
            }
            perPlayer.append(batches)
        }
        runtime.spawnBatches = perPlayer
    }

    /// 批次数量（FUN_00057af0 重建）[macho]。
    ///
    /// `low = trunc(min + minInc*spInc)`、`high = trunc(max + minInc*spInc)`，各自钳到 >= 0；
    /// `high > low` → `rng.nextInt(high - low) + low`，否则 `low`。
    /// 注意：加载器已把 XML `maxinc` 覆盖进 `minInc` 槽，运行时不重复加 `maxInc`。
    private func makeBatch(spawner: Spawner, spInc: Int32) -> SpawnBatch {
        let inc = Float(spInc)
        let low = truncToInt32(spawner.min + spawner.minInc * inc)
        let high = truncToInt32(spawner.max + spawner.minInc * inc)

        let count: Int32
        if high > low {
            count = rng.nextInt(high - low) &+ low
        } else {
            count = low
        }

        var batch = SpawnBatch()
        batch.kinds = resolveTypeSequence(spawner: spawner)
        batch.remaining = count
        batch.total = count
        batch.timer = max(0, spawner.delay + spawner.delayInc * inc)
        return batch
    }

    /// 初始化阶段一次性解析类型序列：显式 fruit/bomb 保序，random 按权重抽一次。
    private func resolveTypeSequence(spawner: Spawner) -> [Int32] {
        var kinds: [Int32] = []
        kinds.reserveCapacity(spawner.types.count)
        for kind in spawner.types {
            switch kind {
            case .fruit(let id):
                kinds.append(id)
            case .bomb:
                kinds.append(Constants.EntityPool.bombSlot)
            case .random:
                kinds.append(drawRandomFruit())
            }
        }
        return kinds
    }

    /// 普通模式权重抽取：按 `FruitInfo.chance` 累计和、保持文档顺序。
    /// 无正权重候选 → 空槽（-1），**不以水果 0 兜底** [macho]。
    private func drawRandomFruit() -> Int32 {
        var cumulative: [Int64] = []
        var total: Int64 = 0
        for fruit in fruits {
            total += max(0, Int64(fruit.chance ?? 0))
            cumulative.append(total)
        }
        guard total > 0 else { return Constants.EntityPool.emptySlot }

        let bound = total >= Int64(Int32.max) ? Int32.max : Int32(total)
        let roll = Int64(rng.nextInt(bound))
        for (index, boundary) in cumulative.enumerated() where roll < boundary {
            return fruits[index].typeID
        }
        return Constants.EntityPool.emptySlot
    }

    // MARK: Private — step 3

    private func runSpawnLoop(dt: Float, player: Int) {
        guard !waves.isEmpty,
              runtime.currentWaveIndex >= 0,
              runtime.currentWaveIndex < waves.count else { return }
        let wave = waves[runtime.currentWaveIndex]
        guard player >= 0, player < runtime.spawnBatches.count else { return }
        guard runtime.spawnBatches[player].count == wave.spawners.count else { return }

        let inc = Float(runtime.currentWaveSpInc)
        var batches = runtime.spawnBatches[player]

        for index in batches.indices {
            guard batches[index].remaining > 0 else { continue }
            batches[index].timer -= dt

            while batches[index].remaining > 0 && batches[index].timer <= 0 {
                let kind = takeKind(from: &batches[index])
                emitSpawn(kind: kind, spawner: wave.spawners[index], wave: wave)
                batches[index].remaining -= 1
                runtime.spawnFlag[player] = 1

                if batches[index].remaining > 0 {
                    let spawner = wave.spawners[index]
                    let interval = spawner.delay + spawner.delayInc * inc
                    batches[index].timer += max(0, interval)
                }
            }
        }

        runtime.spawnBatches[player] = batches
    }

    private func takeKind(from batch: inout SpawnBatch) -> Int32 {
        guard !batch.kinds.isEmpty else {
            batch.cursor += 1
            return Constants.EntityPool.emptySlot
        }
        let index = batch.cursor % batch.kinds.count
        batch.cursor += 1
        return batch.kinds[index]
    }

    // MARK: Private — step 4

    private func tickFreezeRemaining(dt: Float) {
        // [待验证] 多玩家时只让第一个归零的玩家驱动全局选波；原版 per-player 语义未闭合。
        for player in 0..<playerCount where !freezeTriggered[player] {
            if runtime.freezeRemaining[player] > 0 {
                runtime.freezeRemaining[player] = max(0, runtime.freezeRemaining[player] - dt)
            }
            guard runtime.freezeRemaining[player] <= 0 else { continue }

            freezeTriggered[player] = true
            runtime.freezeOnTriggerCount += 1                 // +0x208 += 1
            events?.onFreeze(playerIndex: player)             // vtable+0x38

            // §5.3 步骤 4 末尾：freeze 结束 → 选下一波（不再用 forceSpawn）
            selectNextWave()
            break
        }
    }

    // MARK: Private — step 5

            runtime.bombArmTimer = rng.nextFloat() * 10.0 + 10.0
        case 1:
            if runtime.bombArmFlag == 1 {
                runtime.bombState = 2
            }
        default:
            break
        }
    }

        if kind == Constants.EntityPool.bombSlot {
            runtime.bombCount += 1
            spawnSink?.spawnBomb(from: spawner, wave: wave)
        } else if kind >= 0 {
            spawnSink?.spawnFruit(kind: kind, from: spawner, wave: wave)
        }
        // -1：空槽跳过（不生成）
    }

    /// 向零取整并钳到 >= 0 的 Float → Int32（NaN / 无穷 / 越界都安全）。
    private func truncToInt32(_ value: Float) -> Int32 {
        guard value.isFinite else { return value > 0 ? Int32.max : 0 }
        if value <= 0 { return 0 }
        if value >= 2_147_483_520 { return Int32.max }
        return Int32(value.rounded(.towardZero))
    }

public extension WaveInfo {

    /// `until` 语义后处理（core_logic_notes §4.4 + T-027 精修；
    /// **[macho] 独有**，exe 未见；精确符合 `FUN_00053cb8` 末尾循环）。
    ///
    /// 规则（按序执行，顺序不可交换）：
    ///  1. 非空且精确等于小写 `"forever"` → `-2`；原版使用 `strcmp`，不忽略大小写。
    ///  2. 其他非空串按 C `atoi` 读取数字前缀；结果 `>= 0 && >= waveNo[i]` 才采纳。
    ///  3. 仅对**仍为 -1**（空串 / 未采纳）的条目：
    ///     a. 先设为 `-2`（forever 兜底）
    ///     b. 从**所有** `waveNo[j] > waveNo[i]` 中取最小 `waveNo - 1`
    ///     c. 若无严格更大的 waveNo（当前是最大 / 全部重复），保持 `-2`
    ///  4. **显式有效的 `until` 绝不做旧 step3 改写**。
    ///
    /// 注意：`atoi("garbage") == 0`。因此 waveNo=0 的非空非法串会采纳 0，
    /// 这与空串缺省不同；不能用 Swift 的严格 `Int32(token)` 替代。
    ///
    /// - Parameters:
    ///   - rawTokens: XML `until` 原始串数组（空串表示属性缺失）
    ///   - waveNos:   每波原始 `waveNo`（严格与 rawTokens 等长；可重复）
    /// - Returns: 与 `rawTokens` 等长的后处理结果
    static func postProcessUntil(rawTokens: [String], waveNos: [Int32]) -> [Int32] {
        let n = rawTokens.count
        guard n > 0 else { return [] }
        precondition(waveNos.count == n,
                     "postProcessUntil: waveNos 必须与 rawTokens 等长（禁止下标兜底）")

        var result = [Int32](repeating: Constants.WaveDefaults.untilUnparsed, count: n)
        for i in 0..<n {
            let token = rawTokens[i]
            guard !token.isEmpty else { continue }
            if token == "forever" {
                result[i] = Constants.WaveDefaults.untilForever
                continue
            }
            let parsed = cAtoi(token)
            if parsed >= 0 && parsed >= waveNos[i] {
                result[i] = parsed
            }
        }

        for i in 0..<n where result[i] == Constants.WaveDefaults.untilUnparsed {
            result[i] = Constants.WaveDefaults.untilForever
            let currentNo = waveNos[i]
            var minGreater: Int32?
            for otherNo in waveNos where otherNo > currentNo {
                if minGreater == nil || otherNo < minGreater! {
                    minGreater = otherNo
                }
            }
            if let g = minGreater {
                result[i] = g - 1
            }
        }
        return result
    }

    /// 本任务所需的 C `atoi` 语义：ASCII 空白、可选符号、数字前缀；无数字返回 0。
    /// 超出 Int32 时做饱和保护；原版 C 溢出属未定义行为，不把它宣称为官方规则。
    private static func cAtoi(_ token: String) -> Int32 {
        let bytes = Array(token.utf8)
        var index = 0
        while index < bytes.count {
            switch bytes[index] {
            case 9, 10, 11, 12, 13, 32: index += 1
            default: break
            }
            if index >= bytes.count || !(9...13).contains(bytes[index]) && bytes[index] != 32 {
                break
            }
        }

        var negative = false
        if index < bytes.count, bytes[index] == 45 || bytes[index] == 43 {
            negative = bytes[index] == 45
            index += 1
        }

        let limit = negative ? Int64(Int32.max) + 1 : Int64(Int32.max)
        var value: Int64 = 0
        while index < bytes.count, bytes[index] >= 48 && bytes[index] <= 57 {
            let digit = Int64(bytes[index] - 48)
            value = value > (limit - digit) / 10 ? limit : value * 10 + digit
            index += 1
        }
        if negative {
            return value >= Int64(Int32.max) + 1 ? .min : Int32(-value)
        }
        return Int32(value)
    }

    /// 就地应用后处理结果（辅助入口）。
    ///
    /// - Parameters:
    ///   - waves:     待后处理的 WaveInfo 数组（要求每项 `waveNo >= 0` 已由解析层填好）
    ///   - rawTokens: XML `until` 原始串数组（与 `waves` 顺序一致）
    ///
    /// ⚠️ 本 API 不再用 `String($0.until)` 反推 token —— Int32 → String 会丢失原始字面量
    ///    （如 `forever` / 前导空串），必须由调用方持有原始串。
    static func applyUntilPostProcess(to waves: inout [WaveInfo], rawTokens: [String]) {
        let waveNos = waves.map { $0.waveNo }
        let processed = postProcessUntil(rawTokens: rawTokens, waveNos: waveNos)
        for i in 0..<min(waves.count, processed.count) {
            waves[i].until = processed[i]
        }
    }
}

/// 确定性 LCG 随机源，固定种子即可复现分布。
/// 与 `FNPBCore.RandomSource` 协议一致。
final class SeededRandomSource: RandomSource {

    private var state: UInt64

    init(seed: UInt64 = 1) {
        // 避免 0 态锁死
        self.state = seed == 0 ? 1 : seed
    }

    func nextFloat() -> Float {
        // Numerical Recipes LCG（64 位实现）
        state = state &* 6364136223846793005 &+ 1442695040888963407
        // 取高 32 位并规约到 [0,1)
        let bits = UInt32(truncatingIfNeeded: state >> 32)
        return Float(bits) / (Float(UInt32.max) + 1.0)
    }

    func nextInt(_ upperBound: Int32) -> Int32 {
        guard upperBound > 0 else { return 0 }
        let v = Int32(nextFloat() * Float(upperBound))
        // 防御性截断（浮点误差理论上可产生 == upperBound）
        return min(max(v, 0), upperBound - 1)
    }

    func snapshot() -> UInt64 { state }
    func restore(_ s: UInt64) { state = s == 0 ? 1 : s }
}

// MARK: - 测试替身：统计随机调用次数

final class CountingRandomSource: RandomSource {
    private var inner: SeededRandomSource
    private(set) var nextIntCalls = 0
    private(set) var nextFloatCalls = 0

    init(seed: UInt64) {
        self.inner = SeededRandomSource(seed: seed)
    }

    func nextFloat() -> Float {
        nextFloatCalls += 1
        return inner.nextFloat()
    }

    func nextInt(_ upperBound: Int32) -> Int32 {
        nextIntCalls += 1
        return inner.nextInt(upperBound)
    }

    func snapshot() -> UInt64 { inner.snapshot() }
    func restore(_ s: UInt64) { inner.restore(s) }
}

## 审查风险点（Kimi 注意）

1. **选波计数语义**（最高风险）：我按任务卡字面「先递增再筛」实现，`waveActivationCount` 初值 0 → 首轮 `count=1`。若真实 `originalWaveList.json` 的 wave0 `until < 1`，开局将无候选、整个游戏不出果。需核对 `FUN_00054dd8` 中 `count++` 与候选筛选的先后；若应为「先筛后递增」或初值 -1，只需改 `selectNextWave` 前两行。
2. **`maxChance` 来源**：取 `WaveInfo.chance`（缺省 fallback 90）。任务卡未说明 maxChance 是 `chance` / 100 / defaults.waveChance，属推断，需反编译核对。
3. **`currentChance*10` 权重的取整**：用 Float→Int32 向零截断，`regrowth=0.25` 时权重 2。原版若四舍五入或整数化，分布会不同（任务卡未给依据）。
4. **全零权重候选**：多候选且总权重 0 时取文档顺序首个 [待验证]；原版分支未在导出文本体现。
5. **生成节奏**：`while` 在 `delay=0` 时同帧可出完全部批次。原版可能每帧只出一个，需核对 `FUN_00056098` 循环写法（本卡未给细节）。
6. **freeze 归零 → `selectNextWave` 的连跳**：若真实数据 `nextWait=0`，会每帧连选波；`waitForEntities/waitForProcessing` 未接入（EntityStore 接口无法闭合），只保留计时本身。
7. **多玩家**：`tickFreezeRemaining` 只让首个归零玩家驱动全局选波，且 `selectNextWave` 会重设所有玩家 freeze；原版 per-player 语义未闭合。
8. **`spawnFlag`**：只在生成时置 1，但没有任何地方消费/清零它（原版语义未闭合）。
9. **编译风险（我看不到的文件）**：`OriginalContentLoader.swift` 若仍在赋值 `bombTriggerRemaining/fruitSpawnRemaining`，删字段后会编译失败，需同步删除；`App/GameWorld` 若调用 `forceSpawn()` 或 `triggerExplosion(...)`，需同步改为新 API。
10. **`SpawnTable.swift` 保留**：调度器已不再使用，文件与其测试仍在（任务卡「删除旧 SpawnTable 路径」我理解为调度器路径，未删文件）。
11. **真实数据测试脆弱**：依赖真实 `nextDelay/nextWait/until` 具体值与 wave0 的 spawner 顺序；Windows 环境无法跑 Swift，需 CI 首轮实测，若 wave0 有多个 spawner 或首生成非 watermelon，需按真实数据调整断言（不建议放宽为 ≥0 任意水果）。
12. **`SpawnBatch` 放在 WaveDirector.swift**：任务卡允许 ContentTypes.swift 增「必要运行时模型」，我选择内聚在调度器文件，Kimi 若要求迁至 ContentTypes 可平移。
