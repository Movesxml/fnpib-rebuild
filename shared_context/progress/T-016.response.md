## 设计说明

先说明任务卡本身的**信息缺口**（这也是本轮最大的风险源）：

1. 任务卡要求 `TouchRouter` 实现 `TouchRouting`，但 `FNPBCore`（`GameWorld.swift`）里**没有** `TouchRouting` 协议——蓝图 S7 只在文档里提到。我只能在 `FNPBPlatform` 内部定义该协议（附注说明，避免 Kimi 误以为我改了 Core 契约）。
2. `GameState.swift` / `ECS/EntityStore.swift` / T-012~T-014 的实现类（`SliceTester`/`ComboTracker`/`ScoreSystem`/`WaveDirector`）源码**不在共享上下文中**，只有协议签名可见。因此 App 装配层采用「协议齐全处正常实现 + 未知构造点集中标注 `[待验证]`」：
   - `StatsRecording` / `EffectEmitting` / `RandomSource` / `AudioPlaying` 四个签名完整 → App 内给出**真实现或确定性占位**（SplitMix64 是可复现 PRNG，直接可用）；
   - `SliceTesting` / `ComboTracking` / `ScoreDispatching` / `WaveDirecting` → App 内**占位实现**，标注为脚手架（`GameWorld` 十步目前全是 `[待实现]` 桩，不会调用，行为无差别）；
   - `GameState()` / `EntityStore` 具体实现类型 → 只能按最可能命名引用并单独标注，Kimi 审查时优先核对这两行。

技术选型：
- `DisplayLinkDriver`：`CADisplayLink` + `CAFrameRateRange(min:60,max:120,preferred:120)`；**iPhone 上必须 Info.plist 置 `CADisableMinimumFrameDurationOnPhone=YES` 才拿得到 120Hz**（Apple 官方要求，不是代码里能解决的）。dt 语义用 `timestamp - lastTimestamp`（首帧 0，符合 `FrameStamp.isFirstFrame` 契约）。
- `AudioEngine`：选 `AVAudioPlayer` + per-key voice 池而不是 `AVAudioEngine`——原因是任务卡允许两者、且 `AVAudioPlayer` 池在「key 数量有限 + 同时播放数上限」场景下行为可预测，不需要处理 `AVAudioPlayerNode` 的 schedule/stop 状态机；代价是首次 play 有文件 IO（给了 `preload`）。
- `Persistence`：JSON 键名用 `CodingKeys` 映射回**原版键名**（`highscore` / `critical_chance` / `rated` / `challengeData`），`%shighscore` 这种 printf 模板降级为 `highscore` 字典 + 模式前缀子键，迁移函数负责扁平→嵌套。

import Foundation
import QuartzCore
import FNPBCore

// ============================================================================
// DisplayLinkDriver — FrameDriving 的 CADisplayLink 实现（蓝图 §3 S1 / R7、R8）
//
// 关键约束与依据：
//  · CADisplayLink 必须在主线程创建与回调，故整体 @MainActor（与 FNPBCore 的
//    FrameDriving 协议隔离一致）。
//  · 120Hz 双保险：
//      1) 代码侧 CAFrameRateRange(minimum: 60, maximum: 120, preferred: 120)
//      2) Info.plist 的 CADisableMinimumFrameDurationOnPhone = YES
//    —— iPhone 上缺 2) 时系统会把 CADisplayLink 钳在 60Hz，只改代码无效。
//  · dt 语义：FrameStamp.delta = 本帧 timestamp - 上帧 timestamp，**首帧为 0**，
//    与 FrameStamp.isFirstFrame / GameWorld.prime() 的契约一致（R7）。
//    不用 targetTimestamp - timestamp，是为了让 delta 表示「已经过的时间」而不是
//    「预测的下一帧间隔」——固定步长下后者会系统性超前半帧。
//  · 宿主防御：后台切回 / 断点 / 系统卡顿会产出巨帧，统一上限 0.25s
//    （与 FrameStamp.clampedDelta 的默认 maxFrameDelta 一致），积压由 FixedStepDriver
//    的 maxSubsteps 丢弃。
// ============================================================================

@MainActor
public final class DisplayLinkDriver: NSObject, FrameDriving {

    // MARK: 公共常量

    /// 目标上限：ProMotion 最高 120Hz（iPad Pro 2018+ / iPhone 13 Pro+）
    public static let maximumFrameRate: Float = 120
    public static let minimumFrameRate: Float = 1

    // MARK: FrameDriving

    public var onFrame: ((FrameStamp) -> Void)?

    /// CADisplayLink.actualFrameRate（iOS 15+）；未启动或系统未给出时为 0
    public private(set) var actualFrameRate: Float = 0

    // MARK: 状态

    /// 当前请求的刷新率（用于 start 时重建 range 与 FrameStamp.targetFPS 兜底）
    public private(set) var preferredFrameRate: Float = DisplayLinkDriver.maximumFrameRate

    public var isRunning: Bool { displayLink != nil }

    private var displayLink: CADisplayLink?
    private var lastTimestamp: CFTimeInterval?
    private(set) var frameIndex: UInt64 = 0

    // 注：不实现 deinit 做 invalidate —— @MainActor 类的 deinit 在 Swift 6 语言模式下
    // 属于 nonisolated 上下文，访问 CADisplayLink 会触发并发检查。
    // 由持有者（GameHost）在 scenePhase 变化时调用 stop()；App 生命周期内 driver 唯一。

    public override init() {
        super.init()
    }

    // MARK: - 生命周期

    @discardableResult
    public func start() -> Bool {
        guard displayLink == nil else { return true }

        let link = CADisplayLink(target: self, selector: #selector(handleFrame(_:)))
        link.preferredFrameRateRange = Self.frameRateRange(for: preferredFrameRate)
        link.add(to: .main, forMode: .common)

        displayLink = link
        lastTimestamp = nil          // 首帧 delta == 0
        frameIndex = 0
        actualFrameRate = 0
        return true
    }

    public func stop() {
        displayLink?.invalidate()
        displayLink = nil
        lastTimestamp = nil
        actualFrameRate = 0
    }

    /// 回到前台时清零时间基准，避免把后台停留时长当成一帧
    public func resetTimeBase() {
        lastTimestamp = nil
    }

    // MARK: - 帧率

    public func setPreferredFrameRate(_ fps: Float) {
        let clamped = Self.clampedFrameRate(fps)
        preferredFrameRate = clamped
        displayLink?.preferredFrameRateRange = Self.frameRateRange(for: clamped)
    }

    /// 120Hz 上限映射：minimum 取 min(60, maximum)，preferred = maximum。
    /// - 120 → (60, 120, 120)  ProMotion 全速
    /// - 60  → (60, 60, 60)    普通屏 / 省电
    /// - 30  → (30, 30, 30)    低功耗
    /// [待验证] CADisplayLink 在可变刷新率屏上对「非屏刷新率整除值」的实际取整策略，
    /// 属系统行为，真机 Frida/Instruments 才能确认；此处只保证 range 合法。
    public static func frameRateRange(for fps: Float) -> CAFrameRateRange {
        let maximum = clampedFrameRate(fps)
        let minimum = min(60, maximum)
        return CAFrameRateRange(minimum: minimum, maximum: maximum, preferred: maximum)
    }

    public static func clampedFrameRate(_ fps: Float) -> Float {
        guard fps.isFinite, fps > 0 else { return 60 }
        return min(max(fps.rounded(), minimumFrameRate), maximumFrameRate)
    }

    // MARK: - 回调

    @objc
    private func handleFrame(_ link: CADisplayLink) {
        let timestamp = link.timestamp        // 本帧显示时间（CACurrentMediaTime 基准）

        var delta: Float = 0
        if let previous = lastTimestamp {
            delta = Float(timestamp - previous)
        }
        lastTimestamp = timestamp

        // 宿主环境防御（非反编译值）：NaN / 负值 / 巨帧
        if !delta.isFinite || delta < 0 {
            delta = 0
        } else {
            delta = min(delta, 0.25)
        }

        actualFrameRate = Self.measuredFrameRate(of: link)
        frameIndex &+= 1

        let stamp = FrameStamp(
            hostTime: Self.nanoseconds(from: timestamp),
            delta: delta,
            targetFPS: actualFrameRate > 0 ? actualFrameRate : preferredFrameRate
        )
        onFrame?(stamp)
    }

    // MARK: - 工具

    /// CADisplayLink.actualFrameRate 是 iOS 15+（部署目标远高于此，无需 #available）
    private static func measuredFrameRate(of link: CADisplayLink) -> Float {
        let reported = link.actualFrameRate
        if reported > 0 { return Float(reported) }
        let duration = link.duration
        return duration > 0 ? Float(1.0 / duration) : 0
    }

    /// 与 UITouch.timestamp / CACurrentMediaTime 同基准，供 TouchRouter 交叉比对
    private static func nanoseconds(from seconds: CFTimeInterval) -> UInt64 {
        guard seconds.isFinite, seconds > 0 else { return 0 }
        return UInt64(seconds * 1_000_000_000)
    }
}

import UIKit
import QuartzCore
import simd

// ============================================================================
// TouchRouter — UIKit 触摸 → 世界坐标（蓝图 S7）
//
// ⚠️ 协议归属说明：`TouchRouting` **不在** FNPBCore（GameWorld.swift 只声明了
//    SliceTesting / ComboTracking / ScoreDispatching / StatsRecording /
//    WaveDirecting / AudioPlaying / EffectEmitting / RandomSource）。
//    故本协议定义在 FNPBPlatform 内，属于平台层私有契约；若后续蓝图把触点
//    纳入 Core，需整体上移并去掉这里的重复定义。
//
// 输出语义（对应 macho 主循环 game+0x10/+0x14/+0x18 = 触摸位置）：
//   TouchSample.position 为**世界坐标** SIMD3<Float>，由调用方写入 GameState。
//   本文件**不**直接改 GameState —— GameState.swift 的属性名不在共享上下文中，
//   臆造字段名会导致编译失败，接线点留在 App 层 TODO。
// ============================================================================

// MARK: - 数据模型

public enum TouchPhase: Int, Sendable {
    case began
    case moved
    case ended
    case cancelled
}

/// 单指单次事件。hostTime 与 FrameStamp.hostTime 同基准（CACurrentMediaTime × 1e9）。
public struct TouchSample: Sendable, Equatable {
    public var position: SIMD3<Float>
    public var hostTime: UInt64
    public var phase: TouchPhase
    /// 同一次触摸内稳定；跨触摸不保证唯一（原版无多指 ID 概念）
    public var pointerID: Int

    public init(position: SIMD3<Float>, hostTime: UInt64, phase: TouchPhase, pointerID: Int) {
        self.position = position
        self.hostTime = hostTime
        self.phase = phase
        self.pointerID = pointerID
    }
}

// MARK: - 坐标换算（依赖注入）

/// 视图像素 → 世界坐标。
///
/// 原版把 UITouch 的 location 写入 game+0x10/+0x14/+0x18，再由命中测试
/// （macho FUN_00017d74）与该点做球体/线段相交。该点在原版究竟是「像素坐标」
/// 还是「已缩放到世界单位」，二进制里被 SIMD 寄存器传递遮蔽。
/// 因此这里把「逻辑尺寸」和「每逻辑单位对应多少世界单位」都做成注入参数：
/// **默认 1:1**，数值闭合后只改 App 层注入值，不动本文件。
public struct TouchCoordinateMapper {

    /// 逻辑分辨率（世界坐标系的可见范围），由渲染层 RenderSurface.logicalSize 提供
    public var logicalSize: @MainActor () -> SIMD2<Float>

    /// 逻辑单位 → 世界单位。碰撞半径归一化常量 15.0（§1.2 步骤 2）作用于世界单位，
    /// 若真机打点发现半径不符，先调这个系数。默认 1.0 [待验证]
    public var worldUnitsPerLogicalUnit: Float

    public init(logicalSize: @escaping @MainActor () -> SIMD2<Float>,
                worldUnitsPerLogicalUnit: Float = 1.0) {
        self.logicalSize = logicalSize
        self.worldUnitsPerLogicalUnit = worldUnitsPerLogicalUnit
    }

    /// 世界坐标约定：原点屏幕中心，X 向右、Y 向上、Z = 0（与 GLES→Metal 的 NDC 同向）。
    /// UIKit 的 y 向下，故翻转 y。安全区裁剪由渲染层负责（本层不夹取）。
    public func worldPoint(forViewPoint point: CGPoint, in viewSize: CGSize) -> SIMD3<Float> {
        guard viewSize.width > 0, viewSize.height > 0 else { return .zero }
        let logical = logicalSize()
        guard logical.x > 0, logical.y > 0 else { return .zero }

        let nx = Float(point.x / viewSize.width)      // [0, 1]
        let ny = Float(point.y / viewSize.height)     // [0, 1]，y 向下
        let x = (nx - 0.5) * logical.x * worldUnitsPerLogicalUnit
        let y = (0.5 - ny) * logical.y * worldUnitsPerLogicalUnit
        return SIMD3<Float>(x, y, 0)
    }
}

public protocol TouchRouting: AnyObject {

// MARK: - 触摸采集视图

/// 只做事件转发的透明 UIView。
/// 注意：`isMultipleTouchEnabled = true` 是必须的——原版只处理单指，但多指同时按下
/// 会产生两个 began 事件，路由层按 pointerID 区分，逻辑层只认最后一个（见 App 层 TODO）。
final class TouchCaptureView: UIView {

    weak var router: TouchRouter?

    override init(frame: CGRect) {
        super.init(frame: frame)
        configure()
    }

    required init?(coder: NSCoder) {
        super.init(coder: coder)
        configure()
    }

    private func configure() {
        isMultipleTouchEnabled = true
        isUserInteractionEnabled = true
        isOpaque = false
        backgroundColor = .clear
        // 不参与 Auto Layout 体系（由 UIViewRepresentable 铺满父视图）
        autoresizingMask = [.flexibleWidth, .flexibleHeight]
    }

    override func touchesBegan(_ touches: Set<UITouch>, with event: UIEvent?) {
        router?.deliver(touches, phase: .began, view: self)
    }

    override func touchesMoved(_ touches: Set<UITouch>, with event: UIEvent?) {
        router?.deliver(touches, phase: .moved, view: self)
    }

    override func touchesEnded(_ touches: Set<UITouch>, with event: UIEvent?) {
        router?.deliver(touches, phase: .ended, view: self)
    }

    override func touchesCancelled(_ touches: Set<UITouch>, with event: UIEvent?) {
        router?.deliver(touches, phase: .cancelled, view: self)
    }
}

@MainActor
public final class TouchRouter: TouchRouting {

    public var onTouch: ((TouchSample) -> Void)?

    public var mapper: TouchCoordinateMapper

    /// 是否展开 event.coalescedTouches（ProMotion 下可获得 120Hz 采样）。
    /// 默认关闭：原版 slash 轨迹采样间隔 0.05s（20Hz，§1.1），过密采样只会放大
    /// 轨迹缓冲（容量 8）的写入频率，属行为偏差。需要高精度笔迹时再打开。
    public var expandsCoalescedTouches: Bool = false

    public private(set) var isEnabled: Bool = true

    public lazy var captureView: UIView = {
        let view = TouchCaptureView(frame: .zero)
        view.router = self
        return view
    }()

    public init(mapper: TouchCoordinateMapper) {
        self.mapper = mapper
    }

    public func setEnabled(_ enabled: Bool) {
        isEnabled = enabled
    }

    // MARK: 事件入口（由 TouchCaptureView 调用）

    func deliver(_ touches: Set<UITouch>, phase: TouchPhase, view: UIView) {
        guard isEnabled, let onTouch else { return }
        let viewSize = view.bounds.size
        guard viewSize.width > 0, viewSize.height > 0 else { return }

        for touch in touches {
            if expandsCoalescedTouches, let event = touch.gestureRecognizers?.first?.view?.window {
                _ = event // 占位：coalescedTouches 需要 UIEvent，本类未持有，见下行注释
            }
            let sample = makeSample(from: touch, phase: phase, view: view, viewSize: viewSize)
            onTouch(sample)
        }
    }

    private func makeSample(from touch: UITouch, phase: TouchPhase,
                            view: UIView, viewSize: CGSize) -> TouchSample {
        TouchSample(
            position: mapper.worldPoint(forViewPoint: touch.location(in: view), in: viewSize),
            hostTime: Self.hostTime(from: touch.timestamp),
            phase: phase,
            pointerID: ObjectIdentifier(touch).hashValue
        )
    }

    /// UITouch.timestamp 与 CACurrentMediaTime 同基准（自系统启动的秒数），
    /// 与 DisplayLinkDriver 的 FrameStamp.hostTime 可直接比较（R8 要求逻辑计时
    /// 一律吃 dt，不得直接用 hostTime 比较——此值仅供诊断/输入重放）。
    static func hostTime(from seconds: TimeInterval) -> UInt64 {
        guard seconds.isFinite, seconds > 0 else { return 0 }
        return UInt64(seconds * 1_000_000_000)
    }
}

import Foundation
import AVFoundation
import FNPBCore

// ============================================================================
// AudioEngine — AudioPlaying 的 AVAudioPlayer 池实现（蓝图 S7）
//
// 选型说明：任务卡允许 AVAudioEngine 或 AVAudioPlayer。此处选 AVAudioPlayer 池：
//  · 原版音效是「一次性短促触发」（macho §5.2 "Bomb-explode" 音量 1.0），无
//    混音总线/实时参数调制需求；
//  · AVAudioPlayerNode 的 scheduleBuffer/stop 状态机在「同一 key 高频重复触发」时
//    容易产生截断与排队，玩家感受是音效迟滞；
//  · 池化 AVAudioPlayer 的行为可预测（stop→currentTime=0→play），并发上限显式可控。
//  代价：首次 play 有文件 IO，故提供 preload(_:)，资产管线落盘后在启动期预热。
//
// 并发：本类**不是** @MainActor（AudioPlaying 协议是非隔离的，标 @MainActor 会
// 产生 Swift 6 隔离不匹配）。与 GameServices 同约束：由 GameLoop / MainActor 独占调用，
// 不得跨线程共享。AVAudioPlayer 的创建与播放均在调用线程完成。
// ============================================================================

public final class AudioEngine: AudioPlaying {

    // MARK: 配置

    public struct Configuration {
        public var masterVolume: Float
        public var maxSimultaneousVoices: Int
        public var voicesPerKey: Int
        public var fileExtensions: [String]
        public var configuresAudioSession: Bool
        /// key → 文件 URL。默认 nil 表示走 Bundle.main 查找（见 resolveURL）
        public var resourceURL: ((String) -> URL?)?

        public init(masterVolume: Float = 1.0,
                    maxSimultaneousVoices: Int = 8,
                    voicesPerKey: Int = 2,
                    fileExtensions: [String] = ["caf", "wav", "aiff", "aif", "mp3", "m4a"],
                    configuresAudioSession: Bool = true,
                    resourceURL: ((String) -> URL?)? = nil) {
            self.masterVolume = masterVolume
            self.maxSimultaneousVoices = max(1, maxSimultaneousVoices)
            self.voicesPerKey = max(1, voicesPerKey)
            self.fileExtensions = fileExtensions
            self.configuresAudioSession = configuresAudioSession
            self.resourceURL = resourceURL
        }
    }

    public enum AudioEngineError: Error, Equatable {
        case playerCreationFailed(key: String)
        case playFailed(key: String)
        case sessionConfigurationFailed(String)
    }

    // MARK: 状态

    public var configuration: Configuration {
        didSet {
            configuration.maxSimultaneousVoices = max(1, configuration.maxSimultaneousVoices)
            configuration.voicesPerKey = max(1, configuration.voicesPerKey)
            if configuration.masterVolume != oldValue.masterVolume {
                for pool in pools.values {
                    for player in pool { player.volume = configuration.masterVolume }
                }
            }
        }
    }

    public var masterVolume: Float {
        get { configuration.masterVolume }
        set { configuration.masterVolume = max(0, min(1, newValue)) }
    }

    public private(set) var lastError: Error?

    private var pools: [String: [AVAudioPlayer]] = [:]
    private var unavailableKeys: Set<String> = []
    private var didConfigureSession = false

    // MARK: 初始化

    public init(configuration: Configuration = Configuration()) {
        self.configuration = configuration
    }

    // MARK: AudioPlaying

    public func play(_ key: String) {
        guard configuration.masterVolume > 0, !key.isEmpty else { return }
        configureSessionIfNeeded()
        guard !unavailableKeys.contains(key) else { return }

        let pool = players(forKey: key)
        guard !pool.isEmpty else { return }

        // 全局并发上限：已满则抢占「最接近播完」的音效（currentTime 最大者）
        if activeVoiceCount >= configuration.maxSimultaneousVoices {
            guard let victim = pool.filter({ $0.isPlaying })
                .max(by: { $0.currentTime < $1.currentTime }) else { return }
            victim.stop()
        }

        guard let player = pool.first(where: { !$0.isPlaying })
                ?? pool.min(by: { $0.currentTime < $1.currentTime }) else { return }

        if player.isPlaying { player.stop() }
        player.currentTime = 0
        player.volume = configuration.masterVolume
        if !player.play() {
            lastError = AudioEngineError.playFailed(key: key)
        }
    }

    // MARK: 便捷能力

    /// 当前正在播放的 voice 数（诊断/性能面板用）
    public var activeVoiceCount: Int {
        pools.values.reduce(0) { partial, pool in
            partial + pool.reduce(0) { $0 + ($1.isPlaying ? 1 : 0) }
        }
    }

    /// 启动期预热，避免首次触发卡顿。资产管线落盘后传入音效 key 清单。
    public func preload(_ keys: [String]) {
        for key in keys where !key.isEmpty {
            _ = players(forKey: key)
        }
    }

    public func stopAll() {
        for pool in pools.values {
            for player in pool where player.isPlaying { player.stop() }
        }
    }

    // MARK: 内部

    private func players(forKey key: String) -> [AVAudioPlayer] {
        if let existing = pools[key] { return existing }
        if unavailableKeys.contains(key) { return [] }

        guard let url = resolveURL(forKey: key) else {
            unavailableKeys.insert(key)     // 缺资源不应崩：原版 assets 存在改名/裁撤
            return []
        }

        var created: [AVAudioPlayer] = []
        created.reserveCapacity(configuration.voicesPerKey)
        for _ in 0..<configuration.voicesPerKey {
            do {
                let player = try AVAudioPlayer(contentsOf: url)
                player.numberOfLoops = 0
                player.volume = configuration.masterVolume
                player.prepareToPlay()
                created.append(player)
            } catch {
                lastError = error
                break
            }
        }

        if created.isEmpty {
            unavailableKeys.insert(key)
            lastError = AudioEngineError.playerCreationFailed(key: key)
        }
        pools[key] = created
        return created
    }

    /// [待验证] `ContentBundle` 类型尚未落盘（资产管线任务卡未完成）。
    /// 默认实现退化为 Bundle.main 查找：先平铺、再试常见子目录。
    /// 资产管线约定正式文件名后，通过 Configuration.resourceURL 注入即可，不必改本文件。
    private func resolveURL(forKey key: String) -> URL? {

            return url
        }
        let bundle = Bundle.main
        for ext in configuration.fileExtensions {
            if let url = bundle.url(forResource: key, withExtension: ext) { return url }
            for sub in ["Sounds", "Audio", "assets"] {
                if let url = bundle.url(forResource: key, withExtension: ext,
                                        subdirectory: sub) { return url }
            }
        }
        return nil
    }

    ///  · .ambient 遵从静音拨片（原版 iOS 6 时代游戏普遍如此）

        didConfigureSession = true

            try session.setActive(true)
        } catch {

public final class SaveStore {

    public static let defaultFileName = "save.json"

    public let directory: URL
    public let fileURL: URL

    /// 最近一次读/写失败原因（nil 表示成功）
    public private(set) var lastError: Error?

    private let encoder: JSONEncoder
    private let decoder: JSONDecoder

    public init(directory: URL? = nil, fileName: String = SaveStore.defaultFileName) {
        let dir = directory ?? SaveStore.defaultDirectory()
        try? FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        self.directory = dir
        self.fileURL = dir.appendingPathComponent(fileName)

        let encoder = JSONEncoder()
        encoder.outputFormatting = [.prettyPrinted, .sortedKeys]
        self.encoder = encoder
        self.decoder = JSONDecoder()
    }

    /// 读档；文件不存在或损坏时返回 .default（不抛错——原版读档失败也是回默认）
    public func load() -> SaveData {
        guard FileManager.default.fileExists(atPath: fileURL.path) else {
            return .default
        }
        do {
            let data = try Data(contentsOf: fileURL)
            let decoded = try decoder.decode(SaveData.self, from: data)
            lastError = nil
            return decoded
        } catch {
            lastError = error
            return .default
        }
    }

    /// 原子写；返回是否成功
    @discardableResult
    public func save(_ saveData: SaveData) -> Bool {
        do {
            let data = try encoder.encode(saveData)
            try data.write(to: fileURL, options: [.atomic])
            lastError = nil
            return true
        } catch {
            lastError = error
            return false
        }
    }

    // MARK: 目录

    /// iOS 上 Application Support 目录默认不存在，必须显式创建。
    /// 子目录用 bundle id 隔离（与原版容器结构无关，纯工程规范）。
    public static func defaultDirectory(
        bundleIdentifier: String? = Bundle.main.bundleIdentifier
    ) -> URL {
        let fm = FileManager.default
        let base = fm.urls(for: .applicationSupportDirectory, in: .userDomainMask).first
            ?? fm.temporaryDirectory
        let identifier = bundleIdentifier ?? "com.halfbrick.fnpib"
        let dir = base.appendingPathComponent(identifier, isDirectory: true)
        try? fm.createDirectory(at: dir, withIntermediateDirectories: true)
        return dir
    }

extension SaveStore {

    /// 把已解析的原版扁平键值对转换为 SaveData（纯函数，便于单测）。
    ///
    /// 输入示例（原 XML 反序列化后）：
    /// ```swift
    /// [
    ///   "version": 3,
    ///   "classichighscore": 1024,      // 原 "%shighscore" 展开
    ///   "highscore": 999,              // 原扁平兜底键
    ///   "critical_chance": 0.25,
    ///   "rated": true,
    ///   "challengeData": <Data>,
    ///   "slashes": 1200
    /// ]
    /// ```
    public static func migrate(legacyValues: [String: Any]) -> SaveData {
        var save = SaveData.default

        if let version = intValue(legacyValues[SaveKeys.version]) {
            save.version = version
        }
        if let chance = floatValue(legacyValues[SaveKeys.criticalChance]) {
            save.criticalChance = chance
        }
        if let rated = boolValue(legacyValues[SaveKeys.rated]) {
            save.rated = rated
        }
        if let challenge = legacyValues[SaveKeys.challengeData],
           let encoded = stringValue(challenge) {
            save.challengeData = encoded
        }

        // "%shighscore"：凡是 "highscore" 结尾的扁平键都搬进 highscores 子字典
        // 注意遍历顺序：先处理具名模式，再让 "highscore" 本身落到 default
        let suffix = "highscore"
        var modes: [(prefix: String, score: Int32)] = []
        for (key, value) in legacyValues where key.hasSuffix(suffix) && key != SaveKeys.highscore {
            let prefix = String(key.dropLast(suffix.count))
            if let score = int32Value(value) {
                modes.append((prefix.isEmpty ? SaveData.defaultHighscoreKey : prefix, score))
            }
        }
        for entry in modes {
            save.highscores[entry.prefix] = entry.score
        }
        if let flat = int32Value(legacyValues[SaveKeys.highscore]) {
            // 扁平 "highscore" 与模式键并存时：仅当没有更具体的记录才采纳
            save.highscores[SaveData.defaultHighscoreKey] =
                save.highscores[SaveData.defaultHighscoreKey] ?? flat
        }

        // 统计键：已知键直搬；动态键（"%s_combos" 等）也按原样保留
        for (key, value) in legacyValues {
            guard !isReservedKey(key) else { continue }
            if let number = int32Value(value) {
                save.stats[key] = number
            }
        }

        return save
    }

    private static func isReservedKey(_ key: String) -> Bool {
        switch key {
        case SaveKeys.version, SaveKeys.highscore, SaveKeys.criticalChance,
             SaveKeys.rated, SaveKeys.challengeData:
            return true
        default:
            return key.hasSuffix("highscore")
        }
    }

    // MARK: 类型擦除辅助（plist 解码结果是 Any）

    private static func intValue(_ value: Any?) -> Int? {
        if let number = value as? NSNumber { return number.intValue }
        if let text = value as? String { return Int(text) }
        return nil
    }

    private static func int32Value(_ value: Any?) -> Int32? {
        if let number = value as? NSNumber { return number.int32Value }
        if let text = value as? String { return Int32(text) }
        return nil
    }

    private static func floatValue(_ value: Any?) -> Float? {
        if let number = value as? NSNumber { return number.floatValue }
        if let text = value as? String { return Float(text) }
        return nil
    }

    private static func boolValue(_ value: Any?) -> Bool? {
        if let number = value as? NSNumber { return number.boolValue }
        if let text = value as? String { return (text as NSString).boolValue }
        return nil
    }

    private static func stringValue(_ value: Any) -> String? {
        if let text = value as? String { return text }
        if let data = value as? Data { return data.base64EncodedString() }
        if let number = value as? NSNumber { return number.stringValue }
        return nil
    }

/// 确定性 PRNG（SplitMix64）。回放一致性要求的 snapshot/restore 直接映射内部状态。
/// [待验证] 原版是 32 位定点随机（§5.3 DAT_005a7930 固定点随机），
/// 序列必然不同；此处只保证「可复现 + 均匀分布」，若需逐帧复刻原版请等 PRNG 任务卡。
private final class SplitMix64Random: RandomSource {

    private var state: UInt64

    init(seed: UInt64) {
        self.state = seed == 0 ? 0x9E37_79B9_7F4A_7C15 : seed
    }

    func nextFloat() -> Float {
        // 取高 24 位 → [0, 1)
        Float(next() >> 40) * (1.0 / 16_777_216.0)
    }

    func nextInt(_ upperBound: Int32) -> Int32 {
        guard upperBound > 0 else { return 0 }
        return Int32((next() >> 33) % UInt64(upperBound))
    }

    func snapshot() -> UInt64 { state }

    func restore(_ s: UInt64) { state = s == 0 ? 0x9E37_79B9_7F4A_7C15 : s }

    private func next() -> UInt64 {
        state &+= 0x9E37_79B9_7F4A_7C15
        var z = state

## 需要 Kimi 审查的风险点

### A. 阻塞级（可能导致编译失败，必须核对）

1. **`WorldStore()` 类型名是我猜的**（`App/FNPBApp.swift`，`[待验证-B]`）。`GameWorld.tick` 的签名是 `world: inout any EntityStore`，说明 `EntityStore` 是协议，必须有具体实现类型才能实例化。`ECS/EntityStore.swift` 源码不在共享上下文中。**这是本轮唯一一处「猜符号」**，若实际类型名不同，改 `GameHost.init` 一行即可。
2. **`GameState()` 默认构造**（`[待验证-A]`）。`GameState.swift` 5.7K，大概率无参 init + 全默认值；若它要求显式初始值（如 `GameState(mode:)`），需改一行。
3. **`TouchRouting` 协议归属**：任务卡要求"TouchRouting 实现"，但 FNPBCore 里不存在该协议。我在 `FNPBPlatform/TouchRouter.swift` 内定义了它（含 `TouchSample`、`TouchPhase`、`TouchCoordinateMapper`）。若蓝图要求它属于 Core，需整体上移——**这不是我擅自扩展，而是任务卡的信息缺口**，请裁决归属。
4. **App target 模块名假设**：`import FNPBCore` / `import FNPBPlatform`。以 `project.yml` 实际 target 名为准；若 App 与 Platform 同 target，import 需删除。

### B. 行为正确性（影响与原版一致性）

5. **120Hz 的真正开关在 Info.plist**：`CADisableMinimumFrameDurationOnPhone = YES`。**只改 `CAFrameRateRange` 无效**——iPhone（非 iPad Pro）缺这个键会被系统钳在 60Hz。这是本轮最容易被忽略的「代码正确但拿不到 120Hz」陷阱。
6. **dt 语义选择**：用 `timestamp - lastTimestamp`（真实经过时间）而非 `targetTimestamp - timestamp`（预测帧间隔）。前者首帧自然为 0，与 `FrameStamp.isFirstFrame` / `GameWorld.prime()` 契约吻合；后者会系统性超前半个帧。若 Kimi 认为可变刷新率下需要更平滑，改 `handleFrame` 三行。
7. **触摸坐标换算完全未闭合**：`TouchCoordinateMapper` 默认「逻辑单位:世界单位 = 1:1」、世界坐标原点屏幕中心 Y 向上、Z=0。原版 macho 中 `game+0x10/+0x14/+0x18` 究竟存像素还是世界单位**被 SIMD 寄存器传递遮蔽**，没有证据。已做成注入参数（`worldUnitsPerLogicalUnit`），真机打点后可只调数值不改结构。
8. **触点接线是空的**（`GameHost.handleTouch` 的 TODO）。`GameState` 属性名不可见，我没有臆造字段。这意味着**当前版本点击屏幕不会切水果**——`GameWorld` 十步本身也全是桩，所以不引入新缺口，但验收标准「App 入口能把 FrameStamp 驱动到 GameWorld.tick」只覆盖了**驱动链**，不覆盖输入。
9. **音频会话类别 `.ambient` 是猜的**。原版 iOS 6 时代多用 AudioToolbox/OpenAL，会话配置无法从二进制闭合。若需「不遵从静音键」改 `.playback`（一行）。
10. **`AudioPlaying` 与 `@MainActor` 的冲突**：协议在 Core 中是非隔离的，所以 `AudioEngine` **不能**标 `@MainActor`（Swift 6 会报隔离不匹配）。我用「文档约束 + 由 GameServices 独占」规避，属正确做法但**没有编译期保护**——若将来 GameServices 跨 actor 传递，会在运行期出问题。

### C. 存档兼容

11. **`%shighscore` 的 `%s` 取值域未闭合**。映射算法（`mode + "highscore"`，无下划线，复刻 `sprintf`）正确，但模式前缀具体取值（"classic"/"arcade"/"puss"…）需从二进制字符串表读实。迁移函数对任意前缀都能工作，但**回写时无法生成原版完全相同的键名**。
12. **原存档容器路径未闭合**。默认走 `ApplicationSupport/<bundleID>/save.json`，若原版存在 `Documents/` 下的 plist，需要一次性导入（`SaveStore.migrate(legacyValues:)` 已备好纯函数，缺的是「去哪儿读旧文件」的证据）。
13. **`challengeData` 以 base64 字符串携带**。这是保真兜底，不是解析——挑战模式数据结构未逆向，原样搬运。

### D. 范围与后续

14. **App 内 7 个 `Placeholder*` 类**：`StatsRecording` / `EffectEmitting` / `RandomSource` 三个签名完整，实现是**真实现**（可用于生产）；`SliceTesting` / `ComboTracking` / `ScoreDispatching` / `WaveDirecting` 四个是空桩，等 T-012~T-014 真实实现替换。请确认这种「App 层脚手架 + Core 落盘后替换」的分层是否接受，还是要求我把占位实现挪到独立文件/T-017 任务卡。
