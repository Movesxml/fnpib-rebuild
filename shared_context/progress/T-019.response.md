## 设计说明

本轮按任务卡落盘 5 个文件，保持渲染层独立于游戏逻辑：

1. **MetalContext**：主线程隔离（`@MainActor`），负责设备/命令队列/默认库、按 `BlendMode` 缓存管线、按深度写开关缓存深度状态；包含 `MetalCanvasView`（MTKView 子类）与 `MetalViewRepresentable`。UIKit/SwiftUI 只在本文件出现。
2. **SpriteBatch**：CPU 侧批次描述 + 与 Metal 着色器严格对齐的 `SpriteInstanceGPU`（64 字节 stride，显式 padding）；实例 buffer 的每帧上传队列由 `RenderSurface.swift` 内的三槽环形缓冲实现。
3. **RenderSurface**：`SurfaceRequest` / `EdgeInsetsInset` / `RenderSurface` 协议 + `MetalRenderSurface`。`configure` 更新 viewport 与逻辑尺寸；`submit` 按 `(texture, blend)` 分桶并保序；`endFrame` 每桶一次 `drawPrimitives(instanceCount:)`，不做 GPU 同步等待。
4. **sprite.metal**：实例化 quad，顶点做 2D 旋转 + 逻辑坐标→NDC，片元纹理采样×tint；混合模式由管线状态区分（opaque/alpha/additive）。
5. **TextureLoader**：`MTKTextureLoader` 整页 PNG→`MTLTexture`，按 asset cacheKey 去重；图集 UV 子矩形由调用方提供。

关键兼容性处理：
- 原 GL 的 `glViewport(0,0,w,h)`、`glDepthFunc(GL_LEQUAL)`（0x0203）、`glClear(GL_COLOR|GL_DEPTH)`（0x4500）在注释中锚定到 Metal viewport / `.lessEqual` / clear pass。
- 原 15.0 归一化半径：`logicalSize` 使用逻辑点尺寸（非 drawable 像素），并在 `configure` 注释中明确调用方必须用它参与 `sliceRadiusSquared` 换算，禁止写死像素半径。
- 120Hz：`MTKView.preferredFramesPerSecond` 上限 120；`commit()` 不等待完成，不做 `waitUntilCompleted`。`currentDrawable` 获取是否阻塞标 [待验证]。
- iOS 27 已移除 GLES，本层不再引用任何 GL 符号。
- [待验证]：`MTKTextureLoader.Option.origin` / `.textureStorageMode` 的可用性；`MTKViewDelegate` 在 Swift 6 严格并发下的隔离标注；ProMotion 下 MTKView 实际是否跑到 120Hz；纹理是否为预乘 alpha（当前 alpha 管线按预乘配置）。

import Metal
import MetalKit
import SwiftUI
import UIKit

/// Metal 渲染上下文：设备、命令队列、默认着色器库、管线与深度状态缓存。
///
/// 线程约束：本类型及 MTKView 包装均限定主线程。渲染提交只做主线程侧的
/// command buffer 编码，不在主线程等待 GPU 完成。
@MainActor
public final class MetalContext {

    /// 与原 glClear/颜色附件对应的像素格式。
    /// 使用 sRGB 格式以便 PNG 贴图按 sRGB 采样后正确输出。
    public static let colorPixelFormat: MTLPixelFormat = .bgra8Unorm_srgb

    /// 原 macho 渲染初始化中 glDepthFunc(0x203)=GL_LEQUAL、glDepthMask(1)，
    /// 因此保留深度附件；2D 精灵按提交顺序绘制，opaque 写深度、alpha/additive 不写。
    public static let depthPixelFormat: MTLPixelFormat = .depth32Float

    public let device: MTLDevice
    public let commandQueue: MTLCommandQueue

    private let library: MTLLibrary
    private var pipelines: [BlendMode: MTLRenderPipelineState] = [:]
    private var depthStates: [Bool: MTLDepthStencilState] = [:]

    public init?() {
        guard let device = MTLCreateSystemDefaultDevice(),
              let queue = device.makeCommandQueue(),
              let library = device.makeDefaultLibrary() else {
            return nil
        }
        self.device = device
        self.commandQueue = queue
        self.library = library
    }

    /// 懒创建并缓存三种混合模式的管线。
    /// 着色器文件 `Shaders/sprite.metal` 编译进 app 默认库。
    public func pipeline(for blend: BlendMode) throws -> MTLRenderPipelineState {
        if let cached = pipelines[blend] {
            return cached
        }

        guard let vertexFunction = library.makeFunction(name: "sprite_vertex"),
              let fragmentFunction = library.makeFunction(name: "sprite_fragment") else {
            throw MetalContextError.missingShaderFunction
        }

        let descriptor = MTLRenderPipelineDescriptor()
        descriptor.label = "SpritePipeline-\(blend.rawValue)"
        descriptor.vertexFunction = vertexFunction
        descriptor.fragmentFunction = fragmentFunction
        descriptor.colorAttachments[0].pixelFormat = Self.colorPixelFormat
        descriptor.depthAttachmentPixelFormat = Self.depthPixelFormat

        switch blend {
        case .opaque:
            descriptor.colorAttachments[0].isBlendingEnabled = false

        case .alpha:
            // 预乘 alpha：src=1, dst=1-srcAlpha。
            // 若某图集最终确认是非预乘 PNG，这里应改为 sourceAlpha / oneMinusSourceAlpha。
            descriptor.colorAttachments[0].isBlendingEnabled = true
            descriptor.colorAttachments[0].rgbBlendOperation = .add
            descriptor.colorAttachments[0].alphaBlendOperation = .add
            descriptor.colorAttachments[0].sourceRGBBlendFactor = .one
            descriptor.colorAttachments[0].destinationRGBBlendFactor = .oneMinusSourceAlpha
            descriptor.colorAttachments[0].sourceAlphaBlendFactor = .one
            descriptor.colorAttachments[0].destinationAlphaBlendFactor = .oneMinusSourceAlpha

        case .additive:
            // 加色混合：src=1, dst=1。用于刀光/爆炸等特效。
            descriptor.colorAttachments[0].isBlendingEnabled = true
            descriptor.colorAttachments[0].rgbBlendOperation = .add
            descriptor.colorAttachments[0].alphaBlendOperation = .add
            descriptor.colorAttachments[0].sourceRGBBlendFactor = .one
            descriptor.colorAttachments[0].destinationRGBBlendFactor = .one
            descriptor.colorAttachments[0].sourceAlphaBlendFactor = .one
            descriptor.colorAttachments[0].destinationAlphaBlendFactor = .one
        }

        let state = try device.makeRenderPipelineState(descriptor: descriptor)
        pipelines[blend] = state
        return state
    }

    /// 原 glDepthFunc(GL_LEQUAL, 0x0203) 的 Metal 映射。
    /// opaque 写入深度，alpha/additive 仅测试不写深度。
    public func depthState(writeDepth: Bool) -> MTLDepthStencilState? {
        if let cached = depthStates[writeDepth] {
            return cached
        }

        let descriptor = MTLDepthStencilDescriptor()
        descriptor.label = writeDepth ? "SpriteDepthWrite" : "SpriteDepthRead"
        descriptor.depthCompareFunction = .lessEqual
        descriptor.isDepthWriteEnabled = writeDepth

        guard let state = device.makeDepthStencilState(descriptor: descriptor) else {
            return nil
        }
        depthStates[writeDepth] = state
        return state
    }
}

    case missingShaderFunction
}

        depthStencilPixelFormat = MetalContext.depthPixelFormat

        isPaused = false
        enableSetNeedsDisplay = false

        preferredFramesPerSecond = 120
        clearColor = MTLClearColorMake(0, 0, 0, 1)

        delegate = self
    }

    @available(*, unavailable)
    required init(coder: NSCoder) {
        fatalError("init(coder:) has not been implemented")
    }

    public func draw(in view: MTKView) {
        onDraw?(view)
    }

    public func mtkView(_ view: MTKView, drawableSizeWillChange size: CGSize) {
        onDrawableSizeChange?(size, view.contentScaleFactor)
    }

    public override func layoutSubviews() {
        super.layoutSubviews()
        onDrawableSizeChange?(drawableSize, contentScaleFactor)
    }
}

/// SwiftUI 嵌入入口。
/// 用法：
/// ```swift
/// MetalViewRepresentable(metalContext: context, surface: surface) { view in

///     surface.endFrame()
/// }
/// ```
@MainActor

    public typealias UIViewType = MetalCanvasView

    public let metalContext: MetalContext
    public let surface: MetalRenderSurface?

    private let onDraw: (MTKView) -> Void
    private let onResize: (CGSize, CGFloat) -> Void

    public init(
        metalContext: MetalContext,
        surface: MetalRenderSurface? = nil,
        onDraw: @escaping (MTKView) -> Void = { _ in },
        onResize: @escaping (CGSize, CGFloat) -> Void = { _, _ in }
    ) {
        self.metalContext = metalContext
        self.surface = surface
        self.onDraw = onDraw
        self.onResize = onResize
    }

    public func makeUIView(context: Context) -> MetalCanvasView {
        let view = MetalCanvasView(metalContext: metalContext)
        bind(view)
        surface?.attach(view)
        return view
    }

    public func updateUIView(_ uiView: MetalCanvasView, context: Context) {
        bind(uiView)
        surface?.attach(uiView)
    }

    private func bind(_ view: MetalCanvasView) {
        view.onDraw = onDraw
        view.onDrawableSizeChange = { [weak view] size, scale in
            guard let view else { return }
            onResize(size, scale)
            surface?.configure(
                SurfaceRequest(
                    drawableSize: size,
                    viewSize: view.bounds.size,
                    safeArea: .zero,
                    maxFPS: Float(view.preferredFramesPerSecond),
                    contentScale: scale
                )
            )
        }
    }
}

import Foundation
import Metal
import simd

/// 混合模式。对应原 GL 固定管线中的 opaque / 普通 alpha / 加色混合。
public enum BlendMode: String, Sendable, Hashable, CaseIterable {
    case opaque
    case alpha
    case additive
}

/// 纹理句柄。缓存由 TextureLoader 负责，渲染层只持有 MTLTexture。
///
/// `@unchecked Sendable`：MTLTexture 创建完成后可跨线程读取；本句柄不再修改。
public final class TextureHandle: @unchecked Sendable {

    public let texture: MTLTexture
    public let assetID: String
    public let premultipliedAlpha: Bool
    public let pixelSize: SIMD2<Int>

    public init(
        texture: MTLTexture,
        assetID: String,
        premultipliedAlpha: Bool = true
    ) {
        self.texture = texture
        self.assetID = assetID
        self.premultipliedAlpha = premultipliedAlpha
        self.pixelSize = SIMD2(texture.width, texture.height)
    }
}

/// CPU 侧单实例描述。
///
/// 坐标系：`position` / `size` 使用逻辑点坐标（左上原点、y 向下），
/// 由 RenderSurface 的 logicalSize 做 NDC 映射。这样高 DPI 像素尺寸与
/// 游戏逻辑坐标解耦，切割半径换算不会随机型漂移。
///
/// `rotation` 单位为弧度。
/// `uvOrigin` / `uvSize` 为图集整页上的归一化 UV 子矩形，由调用方给出。
public struct SpriteInstance: Sendable, Equatable {

    public var position: SIMD2<Float>
    public var size: SIMD2<Float>
    public var rotation: Float
    public var uvOrigin: SIMD2<Float>
    public var uvSize: SIMD2<Float>
    public var tint: SIMD4<Float>

    public init(
        position: SIMD2<Float>,
        size: SIMD2<Float>,
        rotation: Float = 0,
        uvOrigin: SIMD2<Float> = SIMD2<Float>(0, 0),
        uvSize: SIMD2<Float> = SIMD2<Float>(1, 1),
        tint: SIMD4<Float> = SIMD4<Float>(1, 1, 1, 1)
    ) {
        self.position = position
        self.size = size
        self.rotation = rotation
        self.uvOrigin = uvOrigin
        self.uvSize = uvSize
        self.tint = tint
    }
}

/// GPU 实例布局。必须与 `Shaders/sprite.metal` 中的 `SpriteInstanceGPU` 逐字段一致。
///
/// Swift 侧布局（64 字节 stride）：
/// - offset 0  : position (SIMD2<Float>)
/// - offset 8  : size     (SIMD2<Float>)
/// - offset 16 : rotation (Float)
/// - offset 20 : _pad0    (Float)
/// - offset 24 : uvOrigin (SIMD2<Float>)
/// - offset 32 : uvSize   (SIMD2<Float>)
/// - offset 40 : _pad1    (SIMD2<Float>)
/// - offset 48 : tint     (SIMD4<Float>, 16 字节对齐)
public struct SpriteInstanceGPU: Sendable {

    public var position: SIMD2<Float>
    public var size: SIMD2<Float>
    public var rotation: Float
    public var _pad0: Float
    public var uvOrigin: SIMD2<Float>
    public var uvSize: SIMD2<Float>
    public var _pad1: SIMD2<Float>
    public var tint: SIMD4<Float>

    public init(_ sprite: SpriteInstance) {
        self.position = sprite.position
        self.size = sprite.size
        self.rotation = sprite.rotation
        self._pad0 = 0
        self.uvOrigin = sprite.uvOrigin
        self.uvSize = sprite.uvSize
        self._pad1 = SIMD2<Float>(0, 0)
        self.tint = sprite.tint
    }
}

/// 顶点 uniform。与 shader 中 `SpriteUniforms` 一致。
public struct SpriteUniforms: Sendable {
    public var viewportSize: SIMD2<Float>

    public init(viewportSize: SIMD2<Float>) {
        self.viewportSize = viewportSize
    }
}

/// 一次提交的 CPU 侧批次。GPU 实例数据由 `MetalRenderSurface` 的
/// `InstanceBufferRing` 每帧上传，不在本结构里持有 MTLBuffer。
public struct SpriteBatch: Sendable {

    public var texture: TextureHandle
    public var instances: [SpriteInstance]
    public var blend: BlendMode

    public init(
        texture: TextureHandle,
        instances: [SpriteInstance],
        blend: BlendMode = .alpha
    ) {
        self.texture = texture
        self.instances = instances
        self.blend = blend
    }
}

import CoreGraphics
import Foundation
import Metal
import MetalKit
import simd

/// Core 层自定义安全区结构，避免渲染层接口依赖 UIKit。
public struct EdgeInsetsInset: Sendable, Equatable {

    public var top: Float
    public var left: Float
    public var bottom: Float
    public var right: Float

    public static let zero = EdgeInsetsInset(top: 0, left: 0, bottom: 0, right: 0)

    public init(top: Float, left: Float, bottom: Float, right: Float) {
        self.top = top
        self.left = left
        self.bottom = bottom
        self.right = right
    }
}

/// 渲染表面配置请求。
///
/// `drawableSize` 为像素尺寸，对应原 `glViewport(0,0,w,h)`；
/// `viewSize` 为逻辑点尺寸，用于游戏逻辑坐标与 NDC 的换算；
/// `safeArea` 只影响 UI 层，不改变游戏坐标系。
public struct SurfaceRequest: Sendable {

    public var drawableSize: CGSize
    public var viewSize: CGSize
    public var safeArea: EdgeInsetsInset
    public var maxFPS: Float
    public var contentScale: CGFloat

    public init(
        drawableSize: CGSize,
        viewSize: CGSize,
        safeArea: EdgeInsetsInset = .zero,
        maxFPS: Float = 120,
        contentScale: CGFloat = 1
    ) {
        self.drawableSize = drawableSize
        self.viewSize = viewSize
        self.safeArea = safeArea
        self.maxFPS = maxFPS
        self.contentScale = contentScale
    }
}

/// 蓝图 S7 RenderSurface 协议。
///
/// 主线程约束：Metal 命令编码在渲染线程/主线程完成，`submit` 不等待 GPU。
@MainActor
public protocol RenderSurface: AnyObject {

    /// 分辨率自适应：替代原 glViewport，同时更新逻辑坐标系。
    func configure(_ request: SurfaceRequest)

    func beginFrame() -> Bool
    func submit(_ batch: SpriteBatch)
    func endFrame()

    /// 逻辑点尺寸。原实现按固定 15.0 归一化碰撞半径，
    /// 因此调用方必须用 logicalSize 参与切片半径换算，不能写死像素半径。
    var logicalSize: SIMD2<Float> { get }
}

/// Metal 实现。
///
/// 设计要点：
/// - `beginFrame` 获取 MTKView 的 currentRenderPassDescriptor / currentDrawable 并创建
///   command buffer + render encoder；不做任何 GPU 等待。
/// - `submit` 仅累积 CPU 实例数据，并按 `(texture, blend)` 分桶；同桶合并成一次
///   instanced draw call。
/// - `endFrame` 把实例数据 memcpy 到三槽环形 MTLBuffer 的当前槽，逐桶编码 draw，
///   最后 `present + commit`。全部 CPU 侧操作，120Hz 下正常情况下远低于 1ms；
///   但 `currentDrawable` 获取本身在 GPU 严重落后时可能阻塞，需真机 Instruments 验证 [待验证]。
@MainActor
public final class MetalRenderSurface: RenderSurface {

    private struct BucketKey: Hashable {
        let textureID: ObjectIdentifier
        let blend: BlendMode
    }

    private struct Bucket {
        let texture: MTLTexture
        let blend: BlendMode
        var instances: [SpriteInstanceGPU]
    }

    private let context: MetalContext
    private let instanceRing: InstanceBufferRing

    private weak var view: MTKView?

    private var viewport = MTLViewport()
    private var _logicalSize = SIMD2<Float>(1, 1)

    private var pendingOrder: [BucketKey] = []
    private var pending: [BucketKey: Bucket] = [:]

    private var currentCommandBuffer: MTLCommandBuffer?
    private var currentEncoder: MTLRenderCommandEncoder?
    private var currentDrawable: CAMetalDrawable?

    public init(context: MetalContext) {
        self.context = context
        self.instanceRing = InstanceBufferRing(device: context.device)
    }

    public var logicalSize: SIMD2<Float> {
        _logicalSize
    }

    public func attach(_ view: MTKView) {
        self.view = view
    }

    public func configure(_ request: SurfaceRequest) {
        let scale = max(1, Float(request.contentScale))
        let drawableWidth = max(1, Float(request.drawableSize.width))
        let drawableHeight = max(1, Float(request.drawableSize.height))

        // viewSize 由 SwiftUI/UIKit 层给出（点）。若布局尚未完成则用 drawable/scale 兜底。
        let logicalWidth = request.viewSize.width > 0
            ? Float(request.viewSize.width)
            : drawableWidth / scale
        let logicalHeight = request.viewSize.height > 0
            ? Float(request.viewSize.height)
            : drawableHeight / scale

        _logicalSize = SIMD2<Float>(max(1, logicalWidth), max(1, logicalHeight))

        // 原 macho FUN_002ee2a0:
        //   glDepthMask(1); glDepthFunc(0x203 /* GL_LEQUAL */);
        //   glClear(0x4500 /* GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT */);
        //   glViewport(0, 0, drawableWidth, drawableHeight)
        // Metal 对应：MTKView 的 render pass clear + 本 viewport。
        viewport = MTLViewport(
            originX: 0,
            originY: 0,
            width: Double(drawableWidth),
            height: Double(drawableHeight),
            znear: 0,
            zfar: 1
        )

        // 原逻辑在固定归一化坐标下运行：碰撞半径按 15.0 归一化
        // （d / 15.0 -> 0.5 * (d / 15.0) + 0.5）。 modernization 后必须由
        // logicalSize 反算 sliceRadiusSquared，例如：
        //   normalizedRadius = pixelRadius * 15.0 / min(logicalSize.x, logicalSize.y)
        // 具体基准轴（短边/高度）待 Frida 打点确认 [待验证]。
        // 这里只保证 logicalSize 是逻辑点尺寸，且不包含 safeArea。
        _ = request.safeArea

        if let view {
            let fps = request.maxFPS > 0 ? request.maxFPS : 120
            view.preferredFramesPerSecond = Int(max(1, min(120, fps)).rounded())
        }
    }

    public func beginFrame() -> Bool {
        guard currentCommandBuffer == nil else {
            return false
        }
        guard let view,
              let passDescriptor = view.currentRenderPassDescriptor,
              let drawable = view.currentDrawable,
              let commandBuffer = context.commandQueue.makeCommandBuffer(),
              let encoder = commandBuffer.makeRenderCommandEncoder(descriptor: passDescriptor) else {
            return false
        }

        encoder.label = "SpriteFrame"
        encoder.setViewport(viewport)

        var uniforms = SpriteUniforms(viewportSize: _logicalSize)
        encoder.setVertexBytes(
            &uniforms,
            length: MemoryLayout<SpriteUniforms>.stride,
            index: 1
        )

        pendingOrder.removeAll(keepingCapacity: true)
        pending.removeAll(keepingCapacity: true)
        instanceRing.beginFrame()

        currentCommandBuffer = commandBuffer
        currentEncoder = encoder
        currentDrawable = drawable
        return true
    }

    public func submit(_ batch: SpriteBatch) {
        guard currentEncoder != nil, !batch.instances.isEmpty else {
            return
        }

        let key = BucketKey(
            textureID: ObjectIdentifier(batch.texture),
            blend: batch.blend
        )

        if pending[key] == nil {
            pending[key] = Bucket(
                texture: batch.texture.texture,
                blend: batch.blend,
                instances: []
            )
            // 保留首次提交顺序。同 texture+blend 的后续批次合并到同一桶；
            // 跨桶顺序保持首次出现顺序，避免字典无序导致画面跳变。
            // 注意：合并同桶可能让后续同桶实例提前到该桶首次位置绘制；
            // 对 2D 游戏通常可接受，若出现透明排序问题需改为 per-batch 不合并。
            pendingOrder.append(key)
        }

        var bucket = pending[key]!
        bucket.instances.append(contentsOf: batch.instances.lazy.map(SpriteInstanceGPU.init))
        pending[key] = bucket
    }

    public func endFrame() {
        guard let commandBuffer = currentCommandBuffer,
              let encoder = currentEncoder,
              let drawable = currentDrawable else {
            resetFrame()
            return
        }

        let stride = MemoryLayout<SpriteInstanceGPU>.stride

        var totalBytes = 0
        for key in pendingOrder {
            guard let bucket = pending[key], !bucket.instances.isEmpty else { continue }
            totalBytes = Self.align(totalBytes, to: 256)
            totalBytes += bucket.instances.count * stride
        }

        let buffer = totalBytes > 0
            ? instanceRing.currentBuffer(minimumLength: totalBytes)
            : nil

        var offset = 0
        for key in pendingOrder {
            guard let bucket = pending[key], !bucket.instances.isEmpty else { continue }

            let byteCount = bucket.instances.count * stride
            let alignedOffset = Self.align(offset, to: 256)

            if let buffer {
                bucket.instances.withUnsafeBufferPointer { pointer in
                    guard let baseAddress = pointer.baseAddress else { return }
                    memcpy(
                        buffer.contents().advanced(by: alignedOffset),
                        baseAddress,
                        byteCount
                    )
                }
            }

            if let buffer,
               let pipeline = try? context.pipeline(for: bucket.blend),
               let depthState = context.depthState(writeDepth: bucket.blend == .opaque) {

                encoder.setRenderPipelineState(pipeline)
                encoder.setDepthStencilState(depthState)
                encoder.setVertexBuffer(buffer, offset: alignedOffset, index: 0)
                encoder.setFragmentTexture(bucket.texture, index: 0)
                encoder.drawPrimitives(
                    type: .triangleStrip,
                    vertexStart: 0,
                    vertexCount: 4,
                    instanceCount: bucket.instances.count
                )
            }

            offset = alignedOffset + byteCount
        }

        encoder.endEncoding()
        commandBuffer.present(drawable)
        commandBuffer.commit()

        resetFrame()
    }

    private func resetFrame() {
        currentCommandBuffer = nil
        currentEncoder = nil
        currentDrawable = nil
        pendingOrder.removeAll(keepingCapacity: true)
        pending.removeAll(keepingCapacity: true)
    }

    @inline(__always)
    private static func align(_ value: Int, to alignment: Int) -> Int {
        (value + alignment - 1) & ~(alignment - 1)
    }
}

/// 三槽实例缓冲环：
/// - 每帧轮转一个槽，避免 CPU 写当前帧时覆盖 GPU 仍可能读取的上一帧数据。
/// - MTKView 的 maximumDrawableCount 默认 3，与槽数一致；若后续改成更多 in-flight 帧，
///   需同步增加槽数 [待验证]。
private final class InstanceBufferRing {

    private let device: MTLDevice
    private var buffers: [MTLBuffer?]
    private var slot = -1

    private static let frameCount = 3

    init(device: MTLDevice) {
        self.device = device
        self.buffers = Array(repeating: nil, count: Self.frameCount)
    }

    func beginFrame() {
        slot = (slot + 1) % buffers.count
    }

    func currentBuffer(minimumLength: Int) -> MTLBuffer? {
        guard slot >= 0, slot < buffers.count else {
            return nil
        }

        if let buffer = buffers[slot], buffer.length >= minimumLength {
            return buffer
        }

        guard let buffer = device.makeBuffer(
            length: max(minimumLength, 1),
            options: .storageModeShared
        ) else {
            return nil
        }

        buffers[slot] = buffer
        return buffer
    }
}

// 必须与 Swift 侧 `SpriteInstanceGPU` 逐字段一致（64 字节 stride）。
// Swift 布局：
//   position(0..7) size(8..15) rotation(16..19) pad0(20..23)
//   uvOrigin(24..31) uvSize(32..39) pad1(40..47) tint(48..63)
struct SpriteInstanceGPU {
    float2 position;
    float2 size;
    float rotation;
    float pad0;
    float2 uvOrigin;
    float2 uvSize;
    float2 pad1;
    float4 tint;
};

// 必须与 Swift 侧 `SpriteUniforms` 一致。
struct SpriteUniforms {
    float2 viewportSize;
};

struct SpriteVertexOut {
    float4 position [[position]];
    float2 uv;
    float4 tint;
};

vertex SpriteVertexOut sprite_vertex(
    uint vertexID [[vertex_id]],
    uint instanceID [[instance_id]],
    const device SpriteInstanceGPU *instances [[buffer(0)]],
    constant SpriteUniforms &uniforms [[buffer(1)]]
) {
    // triangle strip 的四角，单位 quad [-0.5, 0.5]。
    const float2 corners[4] = {
        float2(-0.5, -0.5),
        float2( 0.5, -0.5),
        float2(-0.5,  0.5),
        float2( 0.5,  0.5)
    };

    SpriteInstanceGPU instance = instances[instanceID];
    float2 corner = corners[vertexID];

    // 局部 quad 缩放后做 2D 旋转。
    float2 local = corner * instance.size;
    float c = cos(instance.rotation);
    float s = sin(instance.rotation);
    float2 rotated = float2(
        local.x * c - local.y * s,
        local.x * s + local.y * c
    );

    // position 为逻辑点坐标，左上原点、y 向下。
    float2 logical = instance.position + rotated;
    float2 viewport = max(uniforms.viewportSize, float2(1.0, 1.0));

    // 逻辑坐标 -> NDC：x 向右，y 向下翻转为 NDC 向上。
    float2 ndc = float2(
        logical.x / viewport.x * 2.0 - 1.0,
        1.0 - logical.y / viewport.y * 2.0
    );

    SpriteVertexOut out;
    out.position = float4(ndc, 0.0, 1.0);

    // corner 从 [-0.5,0.5] 映射到 [0,1] 后应用图集 UV 子矩形。
    float2 uvCorner = corner + float2(0.5, 0.5);
    out.uv = instance.uvOrigin + uvCorner * instance.uvSize;
    out.tint = instance.tint;
    return out;
}

fragment float4 sprite_fragment(
    SpriteVertexOut in [[stage_in]],
    texture2d<float> texture [[texture(0)]]
) {
    // 图集整页采样；UV 子矩形由调用方通过实例数据给出。
    // [待验证] 若贴图为 nearest 风格像素图，可将 filter::linear 改为 filter::nearest。
    constexpr sampler spriteSampler(
        coord::normalized,
        address::clamp_to_edge,
        filter::linear
    );

    return texture.sample(spriteSampler, in.uv) * in.tint;
}

import Foundation
import Metal
import MetalKit

/// 贴图资产来源。PNG/WWW 图集整页加载，不做子图切分。
public enum TextureAssetSource: Sendable, Hashable {
    case url(URL)
    case data(Data)
}

/// 贴图资产描述。
///
/// `id` 必须由调用方保证全局唯一，作为缓存键的一部分。
/// `premultipliedAlpha` 对应 T-018 中 .tex 头保留的预乘标记；实际 PNG 是否预乘
/// 需资产管线确认 [待验证]。
public struct TextureAsset: Sendable, Hashable {

    public var id: String
    public var source: TextureAssetSource
    public var srgb: Bool
    public var generateMipmaps: Bool
    public var premultipliedAlpha: Bool

    public init(
        id: String,
        source: TextureAssetSource,
        srgb: Bool = true,
        generateMipmaps: Bool = false,
        premultipliedAlpha: Bool = true
    ) {
        self.id = id
        self.source = source
        self.srgb = srgb
        self.generateMipmaps = generateMipmaps
        self.premultipliedAlpha = premultipliedAlpha
    }

    public var cacheKey: String {
        var key = "\(id)|srgb=\(srgb)|mip=\(generateMipmaps)|premul=\(premultipliedAlpha)"
        switch source {
        case .url(let url):
            key += "|url=\(url.path)"
        case .data(let data):
            // Data 内容不参与 key，调用方必须用唯一 id 区分不同 data。
            key += "|data=\(data.count)"
        }
        return key
    }
}

/// 蓝图 S7 TextureLoading。渲染层只依赖该协议。
public protocol TextureLoading: AnyObject {
    func load(_ asset: TextureAsset) throws -> TextureHandle
}

public enum TextureLoaderError: Error {
    case textureCreationFailed(assetID: String)
    case unsupportedSource(assetID: String)
}

/// MTKTextureLoader 实现。缓存按 asset.cacheKey 去重，相同图集多次请求返回同一
/// TextureHandle（同一 MTLTexture）。
///
/// 线程：内部 NSLock 串行化缓存与 loader 调用；MTLTexture 创建后只读，
/// `@unchecked Sendable` 由该不变量保证。
public final class TextureLoader: TextureLoading, @unchecked Sendable {

    private let device: MTLDevice
    private let loader: MTKTextureLoader
    private let lock = NSLock()
    private var cache: [String: TextureHandle] = [:]

    public init(device: MTLDevice) {
        self.device = device
        self.loader = MTKTextureLoader(device: device)
    }

    public func load(_ asset: TextureAsset) throws -> TextureHandle {
        lock.lock()
        defer { lock.unlock() }

        if let cached = cache[asset.cacheKey] {
            return cached
        }

        var options: [MTKTextureLoader.Option: Any] = [
            .SRGB: NSNumber(value: asset.srgb),
            .textureUsage: NSNumber(value: MTLTextureUsage.shaderRead.rawValue),
            // [待验证] MTKTextureLoader.Option.textureStorageMode 在 iOS 27 的行为；
            // .private 可避免不必要的 CPU 可读映射，加载由 MetalKit 内部 blit 完成。
            .textureStorageMode: NSNumber(value: MTLStorageMode.private.rawValue),
            .generateMipmaps: NSNumber(value: asset.generateMipmaps),
            // 图集通常按左上原点导出；MTKTextureLoader 默认也是 top-left，
            // 这里显式写出以防默认值变化 [待验证 Option 可用性]。
            .origin: NSNumber(value: MTKTextureLoader.Origin.topLeft.rawValue)
        ]

        let texture: MTLTexture
        switch asset.source {
        case .url(let url):
            texture = try loader.newTexture(URL: url, options: options)

        case .data(let data):
            texture = try loader.newTexture(data: data, options: options)
        }

        guard texture.width > 0, texture.height > 0 else {
            throw TextureLoaderError.textureCreationFailed(assetID: asset.id)
        }

        let handle = TextureHandle(
            texture: texture,
            assetID: asset.id,
            premultipliedAlpha: asset.premultipliedAlpha
        )
        cache[asset.cacheKey] = handle
        return handle
    }
}

## Kimi 审查风险点

1. **重复类型定义风险**：`SurfaceRequest`、`EdgeInsetsInset`、`RenderSurface`、`TextureHandle`、`TextureAsset`、`TextureLoading` 可能已在 `FNPBCore` 或既有 `FNPBRender/ShaderTypes.swift`/`TextureFormat.swift` 中定义。当前按蓝图 S7 放在 `FNPBRender`。若已有同名类型，需要合并或把协议挪到 Core，避免重复声明。
2. **Swift 6 严格并发**：`MetalContext`/`MetalRenderSurface`/`MetalCanvasView` 标了 `@MainActor`；`MetalCanvasView` 继承 `MTKView` 并 conform `MTKViewDelegate`，在 iOS 26/27 SDK 下若 `MTKViewDelegate` 未被标注 `@MainActor`，可能出现隔离一致性编译错误。需要 mac 构建验证；必要时改用独立 nonisolated delegate + `MainActor.assumeIsolated`。
3. **预乘 alpha 假设**：alpha 管线按预乘配置（`sourceRGB=.one`, `destinationRGB=.oneMinusSourceAlpha`）。若资产管线输出非预乘 PNG，会出现边缘发灰/过亮，需切换为 `sourceAlpha` 混合并重新验证。`TextureHandle.premultipliedAlpha` 已保留但未参与管线选择。
4. **sRGB 输出与贴图格式**：`colorPixelFormat = .bgra8Unorm_srgb`、纹理 `.SRGB=true` 是色彩正确路径；若原图集实际是线性/非 sRGB，颜色会偏。需用真实 `fruit_atlas.png` 肉眼比对。
5. **120Hz 阻塞点**：`endFrame` 不做 GPU 等待，但 `view.currentDrawable` 获取在 GPU 落后时可能阻塞主线程；`MTKView.preferredFramesPerSecond=120` 是否在 ProMotion 设备上真正生效也需真机 Instruments 验证。任务卡要求“不占主线程超 1ms”，代码只能保证不主动等待，无法保证驱动层不阻塞。
6. **分桶排序语义**：同 `(texture, blend)` 合并会保留桶首次出现顺序，但可能把后续同桶实例提前到该桶首次位置绘制；2D 半透明重叠时若出现排序问题，需要改为 per-batch 不合并或增加显式 layer/order。
7. **实例缓冲 in-flight 数**：三槽环假设最多 3 帧在飞（与 MTKView drawable 数一致）。若后续增加 command buffer 并发或修改 `maximumDrawableCount`，需同步增加槽数，否则可能覆盖 GPU 正在读的 buffer。
8. **MTKTextureLoader.Option 兼容性**：`.origin`、`.textureStorageMode`、`.SRGB` 的 Option 键与枚举值在 iOS 27 SDK 下需编译验证；`.private` 存储模式对 `newTexture(data:)` 的行为标了 [待验证]。
9. **切割半径换算未闭环**：`logicalSize` 已提供且注释说明必须参与 `sliceRadiusSquared`，但“短边/高度”作为 15.0 归一化基准轴仍是 [待验证]，需 Frida 打点或后续任务卡闭合。
10. **MTKView 嵌入方式**：`MetalViewRepresentable` 默认用 `surface` 自动 `configure`，safeArea 传 `.zero`。若 SwiftUI 层需要真实 safeArea，需在外部再次调用 `surface.configure`，否则 HUD 安全区不生效（游戏坐标系不受影响，符合蓝图）。
