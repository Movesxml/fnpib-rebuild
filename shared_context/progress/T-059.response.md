## 2. `Sources/FNPBUI/GameSnapshot.swift`

### 2.1 在 `ChallengeHUDState` 之前插入 `ChallengeBonusHUDState`

```swift
/// 独立 bonus 结算 HUD 的只读值投影。
/// 所有字段来自 ChallengeBonusSettlementHost，UI 不自行推导结算结果或动画完成时间。
public struct ChallengeBonusHUDState: Sendable, Equatable {
    /// ChallengeBonusSettlementController.totalScore。
    public var totalScore: Int
    /// ChallengeBonusSettlementController.finaleScore。
    public var finaleScore: Int
    /// ChallengeBonusSettlementController.lives 的原始 Int 投影；UI 显示用 displayedLives。
    public var lives: Int
    /// Host 当前分数计数。
    public var scoreCounterValue: Int
    /// Host.resultVisible。
    public var resultVisible: Bool
    /// Host.isBonusFinished：bonus 控制器自身完成。
    public var isBonusFinished: Bool
    /// Host.isFinished：host 已发出 didFinish。
    public var isFinished: Bool
    /// 对应 host.isLifeScoreVisible(index: 1...3)，固定投影 3 项。
    public var lifeScoreVisible: [Bool]

    public init(totalScore: Int,
                finaleScore: Int,
                lives: Int,
                scoreCounterValue: Int,
                resultVisible: Bool,
                isBonusFinished: Bool,
                isFinished: Bool,
                lifeScoreVisible: [Bool]) {
        self.totalScore = totalScore
        self.finaleScore = finaleScore
        self.lives = lives
        self.scoreCounterValue = scoreCounterValue
        self.resultVisible = resultVisible
        self.isBonusFinished = isBonusFinished
        self.isFinished = isFinished
        self.lifeScoreVisible = lifeScoreVisible
    }

    /// 仅用于 UI 显示的生命数，固定在 0...3；原始 lives 仍保留在上面的 lives。
    public var displayedLives: Int {
        min(max(lives, 0), 3)
    }
}
```

### 2.2 在 `ChallengeHUDState` 中添加可选 `bonus` 字段

替换属性区中的这一段：


为：

替换 `ChallengeHUDState.init` 参数列表中的这一段：

```swift

        map: ChallengeMapHUDState? = nil,
```

为：

```swift
        map: ChallengeMapHUDState? = nil,
```

在 init 内对应位置插入赋值：


即放在：

```swift

        self.bonus = bonus
        self.errorMessage = errorMessage
```

## 3. App 投影片段 `challengeHUD`

在 `mapState` 构造完成之后、`return ChallengeHUDState(` 之前插入：

```swift
        let bonusHost: ChallengeBonusSettlementHost? = challengeBonusSettlement
        var bonusState: ChallengeBonusHUDState?
        if let host = bonusHost,
           host.hasBegun,
           let totalScore = host.totalScore,
           let finaleScore = host.finaleScore,
           let lives = host.lives {
            bonusState = ChallengeBonusHUDState(
                totalScore: Int(totalScore),
                finaleScore: Int(finaleScore),
                lives: Int(lives),
                scoreCounterValue: Int(host.scoreCounterValue),
                resultVisible: host.resultVisible,
                isBonusFinished: host.isBonusFinished,
                isFinished: host.isFinished,
                lifeScoreVisible: (1...3).map {
                    host.isLifeScoreVisible(index: Int32($0))
                })
        }
```

`Int32 -> Int` 只在这里做一次；64 位 iOS 上安全。之后 UI 只使用 `Int` 和 `displayedLives` 的 0...3 夹取。

然后把 `return ChallengeHUDState(` 调用中的：

```swift
            map: mapState,
            errorMessage: challengeConfigurationError)
```

替换为：

```swift
            map: mapState,
            bonus: bonusState,
            errorMessage: challengeConfigurationError)
```

`bonusHost` 的写法同时兼容 `challengeBonusSettlement` 是非可选或可选属性；字段来源仍是 Host。

### 4.2 在 `challengeHUD(_:)` 与 `classicHearts(...)` 之间插入面板函数

```swift
    private func challengeBonusPanel(_ bonus: ChallengeBonusHUDState) -> some View {
        VStack(spacing: 10) {
            Text("BONUS")
                .font(.system(size: 13, weight: .heavy, design: .rounded))
                .tracking(2)
                .foregroundStyle(UIPalette.parchment.opacity(0.85))

            Text("\(bonus.scoreCounterValue)")
                .font(.system(size: 40, weight: .black, design: .rounded).monospacedDigit())
                .foregroundStyle(UIPalette.parchment)
                .lineLimit(1)
                .minimumScaleFactor(0.6)

            HStack(spacing: 22) {
                VStack(spacing: 2) {
                    Text("FINALE")
                        .font(.system(size: 11, weight: .heavy, design: .rounded))
                        .tracking(1)
                    Text("\(bonus.finaleScore)")
                        .font(.system(size: 22, weight: .black, design: .rounded).monospacedDigit())
                }

                VStack(spacing: 2) {
                    Text("LIVES")
                        .font(.system(size: 11, weight: .heavy, design: .rounded))
                        .tracking(1)
                    Text("\(bonus.displayedLives) / 3")
                        .font(.system(size: 22, weight: .black, design: .rounded).monospacedDigit())
                }
            }
            .foregroundStyle(UIPalette.parchment)

            HStack(spacing: 8) {
                ForEach(0..<3, id: \.self) { index in
                    let visible = index < bonus.lifeScoreVisible.count
                        && bonus.lifeScoreVisible[index]

                    Circle()
                        .fill(visible ? UIPalette.gold : Color.black.opacity(0.25))
                        .frame(width: 18, height: 18)
                        .overlay(
                            Circle()
                                .stroke(
                                    UIPalette.parchment.opacity(visible ? 0.90 : 0.35),
                                    lineWidth: 1
                                )
                        )
                }
            }

            if bonus.isBonusFinished {
                Text("BONUS COMPLETE")
                    .font(.system(size: 12, weight: .bold, design: .rounded))
                    .foregroundStyle(UIPalette.parchment.opacity(0.80))
            }
        }
        .padding(20)
        .background(RoundedRectangle(cornerRadius: 20).fill(UIPalette.panelFill))
        .padding(.horizontal, 24)
        .allowsHitTesting(false)
    }
```

说明：生命奖励圆点通过 `lifeScoreVisible[0...2]` 直接来自 Host；`displayedLives` 只做 0...3 显示夹取，负数、4、Int32 大值都不会越界或崩溃。

## 5. 可添加的纯值投影测试建议

1. `ChallengeBonusHUDState.displayedLives`：
   - `lives = -1` → `0`
   - `lives = 0` → `0`
   - `lives = 3` → `3`
   - `lives = 4` → `3`
   - `lives = Int.max` → `3`
   - `lives = Int.min` → `0`

2. `ChallengeBonusHUDState` 原样保存 Host 投影值：
   - `totalScore/finaleScore/lives/scoreCounterValue/resultVisible/isBonusFinished/isFinished` 与构造入参相等。
   - `lifeScoreVisible = [false, false, false]`、`[true, true, true]` 均不触发 UI 假设。

3. `ChallengeHUDState` 兼容性：
   - `bonus = nil` 时，既有 `map/resultVisible/resultFinished/canAdvance/errorMessage` 字段保持不变。
   - `bonus != nil` 时，普通结算字段不被改写。

4. Host 投影测试：
   - `begin(totalScore:finaleScore:lives:)` 后断言 `scoreCounterValue == (totalScore &- finaleScore) &- (lives &* 100)`。
   - 对 `index = -1, 0, 1, 2, 3, 4` 断言 `isLifeScoreVisible` 只在 `1...3` 且 `index - 1 < lives` 时为 true。
   - `hasBegun == false` 时 App 投影应得到 `bonus = nil`；`hasBegun == true` 后 `bonus.resultVisible` 直接等于 `host.resultVisible`。
