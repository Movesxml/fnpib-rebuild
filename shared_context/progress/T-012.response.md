3. `findings/deep_slash_macho.md` 的 `FUN_00017d74` 全量反编译（门控链与球体二次确认的算术结构）

每个函数都写明具体锚点；**待 Kimi 补回 slash_geometry.md 后应做一次锚点回填**（已在风险点列出）。

### 关键还原结论（从 FUN_00017d74 直读）
- 门控链顺序：`game+0x38 != 0`（刀形状）→ `0.0 < game+0xf0`（切割半径²）→ `entity+0x38 != 0`（实体形状）→ `PTR[0x18]==0 && PTR[10]==0`（两个全局开关**均关**）。
- 判定结构：`A = entityShape.vtable+8()`（需球体二次确认），`B = gameShape.vtable+0x0C(..., &contact)`（通用形状相交）。
  - `A==0` → 直接返回 `B`；
  - `A==1 && B==0` → false；
  - `A==1 && B==1` → 进入球体二次确认，可把结果由 true 覆盖为 false。
- 二次确认：`dist² = |cutterCenter − sphereCenter|²`；`dist² < r²` → 命中（球心在球内，不进入截面分支）；否则用 `contact` 求 `k = sqrtf(r² − |pt|²)`，取 `±` 极值点与 `cutRadius²`（`game+0xf0`）比较。
- `local_48/44/40 = DAT_0052bfe0/e4/e8 = (0,0,0)`（T-007 已确认 12 字节全 0）→ 极值方向初值为零向量，需由几何补出；`±k` 的构造方向在反编译截断处未闭合 → 本实现取「`pt × cutDirection` 的单位化法线」，标 `[待验证]`。

### 架构决策
- **`contact` 语义统一为「刀形状上最接近被切球心的点」**。理由：反编译用 `|pt|² < r²` 做门，若 `contact` 是球面上的交点则 `|pt| = r` 恒成立、分支永假；取刀面最近点后该门语义自洽（对 line 自动退化为「球心在线段上的投影点」，对 sphere 退化为「朝被切球方向、距离 `d − r_cutter` 的刀面点」）。**这与引擎原始输出可能不同，已标 `[待验证]`。**
- **不为 `GameState` 臆造字段**：`SliceTester` 通过注入的 `(GameState) -> SliceQuery` 取数，`GameState.swift` 字段名确定后接线即可；测试全程只调 `evaluate(query:entity:radiusScale:)`，不构造 `GameState`。

### 兼容性 / iOS 27 相关
纯数学与值类型，无 UIKit/GLES 依赖，无 32→64 位隐患；`Float` 与 armv7 时期单精度一致（`exe` 侧 double 常量已按 T-007 结论统一按 `Float` 使用）。唯一现代侧影响：120Hz 下 `dt≈8.3ms`，轨迹 0.05s 超时意味着每次激活只采 1 点（3 帧以上才达阈），**采样密度需在渲染任务卡单独评估**（见风险点）。

/// slash 轨迹环形缓冲。
///
/// 锚点：`core_logic_notes.md §1.2 步骤 3`（[both]）
/// 原逻辑（macho `FUN_00016214` / exe `FUN_00bda510`）：
/// ```
/// if (+0xa5 == 0) { +0x17c = 0 }                 // 未激活 → 计时归零
/// else {
///     +0x17c += dt
///     if (+0x17c > trailTimeout) {               // 0.05s（Constants.Slash.trailTimeout）
///         slot = (slot + 1) % 8                  // 0x8 槽（Constants.Slash.slotCount）
///         write(&DAT_00557468 + slot*4, ...)
///         +0xa5 = 0; +0x17c = 0
///     }
/// }
/// ```
///
/// 字段映射：
/// - `isActive` ↔ `+0xa5`（slash 轨迹计时活跃）
/// - `elapsed`  ↔ `+0x17c`（slash 轨迹持续计时）
/// - `slot`     ↔ `DAT_005573b4`（全局槽位指针）
///
/// ⚠️ 现代 120Hz 提示：`dt≈8.3ms` 时 0.05s 内最多 6 次采样，超出才写槽；
///    与原 30/60Hz 环境的采样密度不同，渲染侧刀光长度需另行评估（T-012 风险点）。
public struct SlashTrail: Sendable {

    /// 环形缓冲槽（原 `DAT_00557468 + slot*4`，8 槽 vec3）
    public private(set) var samples: [SIMD3<Float>]

    /// 最近写入的槽位（原 `DAT_005573b4`）
    public private(set) var slot: Int

    /// 累计写入次数（诊断/测试用，原逻辑无此字段）
    public private(set) var writeCount: Int

    /// 轨迹计时是否活跃（原 `+0xa5`）
    public private(set) var isActive: Bool

    /// 轨迹持续计时（原 `+0x17c`）
    public private(set) var elapsed: Float

    public init() {
        self.samples = Array(repeating: SIMD3<Float>.zero,
                             count: Constants.Slash.slotCount)
        self.slot = 0
        self.writeCount = 0
        self.isActive = false
        self.elapsed = 0
    }

    /// 槽位容量（原 `% 8`）
    public var capacity: Int { Constants.Slash.slotCount }

    /// 已写入的采样点（按槽序，未写入槽为零向量）
    public var points: [SIMD3<Float>] { samples }

    // MARK: 状态迁移

    /// 开启轨迹计时。锚点：`core_logic_notes.md §1.2 步骤 6.3.a`（`DAT_005d4d80!=0 → +0xa5=1`）
    public mutating func begin() {
        isActive = true
    }

    /// 关闭轨迹计时并归零计时器（原 `+0xa5=0; +0x17c=0`）。
    public mutating func clear() {
        isActive = false
        elapsed = 0
    }

    /// 全量复位（含槽位与采样点）。用于关卡切换/炸弹爆炸后的轨迹丢弃。
    public mutating func reset() {
        isActive = false
        elapsed = 0
        slot = 0
        writeCount = 0
        for i in samples.indices { samples[i] = .zero }
    }

    // MARK: 推进

    /// 推进一帧轨迹计时；超时则写入新采样点。
    ///
    /// 锚点：`core_logic_notes.md §1.2 步骤 3`（[both]）；常量见
    /// `Constants.Slash.trailTimeout`(0.05) / `Constants.Slash.slotCount`(8)。
    ///
    /// - Parameters:
    ///   - dt: 本帧步长（GameWorld 已做 `dt==0` 兜底，见 §1.2 步骤 1）
    ///   - point: 本帧采样点（原 `FUN_00019f10(..., +0xb8, +0xb4)` 的输入）
    /// - Returns: 是否写入了新槽
    @discardableResult
    public mutating func advance(dt: Float, point: SIMD3<Float>) -> Bool {
        // 原：if (+0xa5 == 0) { +0x17c = 0 }
        guard isActive else {
            elapsed = 0
            return false
        }

        elapsed += dt

        // 原：if (trailTimeout < +0x17c) —— 严格大于，边界值不写槽
        guard elapsed > Constants.Slash.trailTimeout else { return false }

        // 原：slot = (slot + 1) % 8
        slot = (slot + 1) % capacity
        samples[slot] = point
        writeCount += 1

        // 原：+0xa5 = 0; +0x17c = 0
        isActive = false
        elapsed = 0
        return true
    }
}

/// 切割判定门控。
///
/// 锚点：`findings/deep_slash_macho.md` FUN_00017d74 门控链（[macho] H）：
/// ```
/// if (game+0x38 != 0 && 0.0 < game+0xf0 && entity != 0

public enum HitTest {

    /// 门控结果（枚举而非 Bool，便于测试定位失败点）
    public enum Gate: Sendable, Equatable {
        case passed
        /// `game +0x38 == 0`：切割形状缺失
        case noCutter
        /// `!(0.0 < game +0xf0)`：切割半径² 非正
        case nonPositiveCutRadius
        /// `entity +0x38 == 0`：实体形状缺失
        case noEntityShape
        /// `PTR[0x28] != 0 || PTR[0x60] != 0`：全局暂停开关开启
        case globalSwitchOn
    }

    /// 按反编译顺序逐项检查门控。
    ///
    /// - Parameters:
    ///   - query: 切割查询上下文
    ///   - entityShape: 实体形状（由调用方从 Entity 构造；nil 表示实体无形状）
    public static func gate(query: SliceQuery, entityShape: ShapeRef?) -> Gate {
        guard query.cutter != nil else { return .noCutter }
        guard query.cutRadiusSquared > 0 else { return .nonPositiveCutRadius }
        guard entityShape != nil else { return .noEntityShape }
        guard !query.globalSwitchA, !query.globalSwitchB else { return .globalSwitchOn }
        return .passed
    }

    /// 便捷布尔版
    public static func passes(query: SliceQuery, entityShape: ShapeRef?) -> Bool {
        gate(query: query, entityShape: entityShape) == .passed
    }
}

//
//  ShapeIntersect.swift
//  FNPBCore
//
//  引擎通用形状相交（原 vtable+0x0C 多态分发）的现代重建（T-012）。
//
//  【锚点】findings/deep_slash_macho.md FUN_00017d74：
//      uVar2 = (**(code **)(**(int **)(param_1 + 0x38) + 0xc))
//                    (gameShape, entityShape, &local_3c);
//  即：切割判定第一段 = 通过虚表 +0x0C 调用「形状 × 形状」相交，并由第三参数
//  输出接触点（12 字节 = vec3）。
//
//  【contact 语义】⚠️ [待验证]
//  引擎原始输出落在 local_3c/38/34，随后被当作「相对实体球心的局部偏移」使用
//  （二次确认中计算 |contact|² 并与 r² 比较）。若 contact 是球面上的交点，
//  则 |contact| ≡ r，`|contact|² < r²` 恒假、截面圆分支永不成立。
//  故本实现把约定定为：**contact = 刀形状上最接近被切球心的点（世界坐标）**，
//  使 `|contact − sphereCenter|² < r²` 在粗判相交后通常成立。
//  该约定替换了引擎原输出，属重建偏差，需 Mach-O 运行期核对（T-012 风险点）。
//
//  【覆盖范围】按任务卡：线-球 / 线-三角 / 球-球 为必需；AABB 参与的组合
//  与球-三角为补全 switch 穷尽性所需，三角-三角与三角-AABB 未实现（返回 false）。
//

import Foundation
import simd

// MARK: - ShapeRef

/// 形状引用（原引擎形状对象的类型擦除）。
///
/// 锚点：`DECISIONS.md [T-006]`「引擎通用形状相交（vtable+0x0C，多态分发线/球/三角）」。
public enum ShapeRef: Sendable, Equatable {

    /// 球：球心 + 半径（原实体形状 `+0x4/+0x8/+0xC` = 位置，`+0x14` = 半径）
    case sphere(center: SIMD3<Float>, radius: Float)

    /// 线段（刀光轨迹；原 slash 轨迹点对）
    case line(a: SIMD3<Float>, b: SIMD3<Float>)

    /// 三角形（网格/多边形切刀）
    case triangle(a: SIMD3<Float>, b: SIMD3<Float>, c: SIMD3<Float>)

    /// 轴对齐包围盒
    case aabb(min: SIMD3<Float>, max: SIMD3<Float>)

    /// 代表中心点。用于球体二次确认的球心距离判定。
    public var center: SIMD3<Float> {
        switch self {
        case let .sphere(c, _):        return c
        case let .line(a, b):          return (a + b) * 0.5
        case let .triangle(a, b, c):   return (a + b + c) / 3
        case let .aabb(mn, mx):        return (mn + mx) * 0.5
        }
    }

    /// 是否球体（对应原 `entityShape->vtable+8()` 返回 1 的语义）。
    /// [待验证]：vtable+8 的确切语义未经运行期确认，仅由 T-006「球体二次确认」推断。
    public var isSpherical: Bool {
        if case .sphere = self { return true }
        return false
    }

    /// 球半径（非球返回 nil）
    public var sphericalRadius: Float? {
        if case let .sphere(_, r) = self { return r }
        return nil
    }
}

// MARK: - ShapeIntersecting

/// 通用形状相交（原 vtable+0x0C 多态分发的协议化）。
public protocol ShapeIntersecting: AnyObject {
    /// 判断两形状是否相交，并输出接触点（世界坐标）。
    ///
    /// - Parameters:
    ///   - a: 形状 A（切割判定中为**刀**形状，原 `game+0x38`）
    ///   - b: 形状 B（切割判定中为**被切实体**形状，原 `entity+0x38`）
    ///   - contact: 输出 = 形状 A 上最接近形状 B 中心（球时）的点
    /// - Returns: 是否相交
    func intersect(_ a: ShapeRef, _ b: ShapeRef, contact: inout SIMD3<Float>) -> Bool
}

// MARK: - 默认实现

/// 无状态实现，可由任意线程持有。
public final class DefaultShapeIntersector: ShapeIntersecting {

    private let epsilon: Float = 1e-8

    public init() {}

    public func intersect(_ a: ShapeRef, _ b: ShapeRef, contact: inout SIMD3<Float>) -> Bool {
        switch (a, b) {

        // 球 × 球
        case let (.sphere(c1, r1), .sphere(c2, r2)):
            return sphereSphere(c1, r1, c2, r2, &contact)

        // 线 × 球
        case let (.line(p0, p1), .sphere(c, r)):
            return lineSphere(p0, p1, c, r, &contact)
        case let (.sphere(c, r), .line(p0, p1)):
            return lineSphere(p0, p1, c, r, &contact)

        // 线 × 三角
        case let (.line(p0, p1), .triangle(v0, v1, v2)):
            return lineTriangle(p0, p1, v0, v1, v2, &contact)
        case let (.triangle(v0, v1, v2), .line(p0, p1)):
            return lineTriangle(p0, p1, v0, v1, v2, &contact)

        // 线 × AABB
        case let (.line(p0, p1), .aabb(mn, mx)):
            return lineAABB(p0, p1, mn, mx, &contact)
        case let (.aabb(mn, mx), .line(p0, p1)):
            return lineAABB(p0, p1, mn, mx, &contact)

        // 球 × 三角
        case let (.sphere(c, r), .triangle(v0, v1, v2)):
            return sphereTriangle(c, r, v0, v1, v2, &contact)
        case let (.triangle(v0, v1, v2), .sphere(c, r)):
            return sphereTriangle(c, r, v0, v1, v2, &contact)

        // 球 × AABB
        case let (.sphere(c, r), .aabb(mn, mx)):
            return sphereAABB(c, r, mn, mx, &contact)
        case let (.aabb(mn, mx), .sphere(c, r)):
            return sphereAABB(c, r, mn, mx, &contact)

        // AABB × AABB
        case let (.aabb(a0, a1), .aabb(b0, b1)):
            return aabbAABB(a0, a1, b0, b1, &contact)

        // 未覆盖组合：[待验证] —— 当前切割判定调用路径（刀 vs 实体球）不涉及
        case (.line, .line), (.triangle, .triangle),
             (.triangle, .aabb), (.aabb, .triangle):
            return false
        }
    }

    // MARK: 球 × 球

    /// 球-球相交。
    /// contact = 被切球心 `c2` 朝刀球心方向、距离 `max(0, d − r1)` 的刀面点。
    private func sphereSphere(_ c1: SIMD3<Float>, _ r1: Float,
                              _ c2: SIMD3<Float>, _ r2: Float,
                              _ contact: inout SIMD3<Float>) -> Bool {
        let diff = c1 - c2
        let d2 = simd_length_squared(diff)
        let rr = r1 + r2
        guard d2 <= rr * rr else { return false }

        let d = d2.squareRoot()
        if d < epsilon {
            // 同心：接触点退化到被切球心
            contact = c2
            return true
        }
        let dir = diff / d
        contact = c2 + dir * Swift.max(0, d - r1)
        return true
    }

    // MARK: 线 × 球

    /// 线-球相交。
    /// contact = 线段上最接近球心的点（clamp 到 [a,b]）。
    private func lineSphere(_ p0: SIMD3<Float>, _ p1: SIMD3<Float>,
                            _ c: SIMD3<Float>, _ r: Float,
                            _ contact: inout SIMD3<Float>) -> Bool {
        let d = p1 - p0
        let dd = simd_length_squared(d)
        if dd < epsilon {
            let dist2 = simd_length_squared(p0 - c)
            guard dist2 <= r * r else { return false }
            contact = p0
            return true
        }
        var t = simd_dot(c - p0, d) / dd
        t = Swift.min(Swift.max(t, 0), 1)
        let closest = p0 + d * t
        guard simd_length_squared(closest - c) <= r * r else { return false }
        contact = closest
        return true
    }

    // MARK: 线 × 三角

    /// 线-三角相交（Möller–Trumbore）。
    /// contact = 线段与三角平面的交点世界坐标。
    private func lineTriangle(_ p0: SIMD3<Float>, _ p1: SIMD3<Float>,
                              _ v0: SIMD3<Float>, _ v1: SIMD3<Float>, _ v2: SIMD3<Float>,
                              _ contact: inout SIMD3<Float>) -> Bool {
        let d = p1 - p0
        let e1 = v1 - v0
        let e2 = v2 - v0
        let pvec = simd_cross(d, e2)
        let det = simd_dot(e1, pvec)
        if abs(det) < epsilon { return false }        // 平行
        let invDet = 1 / det
        let tvec = p0 - v0
        let u = simd_dot(tvec, pvec) * invDet
        guard u >= 0, u <= 1 else { return false }
        let qvec = simd_cross(tvec, e1)
        let v = simd_dot(d, qvec) * invDet
        guard v >= 0, u + v <= 1 else { return false }
        let t = simd_dot(e2, qvec) * invDet
        guard t >= 0, t <= 1 else { return false }
        contact = p0 + d * t
        return true
    }

    // MARK: 线 × AABB

    /// 线-AABB 相交（slab 法，t ∈ [0,1]）。
    private func lineAABB(_ p0: SIMD3<Float>, _ p1: SIMD3<Float>,
                          _ mn: SIMD3<Float>, _ mx: SIMD3<Float>,
                          _ contact: inout SIMD3<Float>) -> Bool {
        let d = p1 - p0
        var tMin: Float = 0
        var tMax: Float = 1

        for axis in 0..<3 {
            let o = p0[axis]
            let dir = d[axis]
            if abs(dir) < epsilon {
                if o < mn[axis] || o > mx[axis] { return false }
            } else {
                var t1 = (mn[axis] - o) / dir
                var t2 = (mx[axis] - o) / dir
                if t1 > t2 { swap(&t1, &t2) }
                tMin = Swift.max(tMin, t1)
                tMax = Swift.min(tMax, t2)
                if tMin > tMax { return false }
            }
        }
        contact = p0 + d * tMin
        return true
    }

    // MARK: 球 × 三角

    /// 球-三角相交：球心到三角最近点距离 ≤ 半径。
    private func sphereTriangle(_ c: SIMD3<Float>, _ r: Float,
                                _ v0: SIMD3<Float>, _ v1: SIMD3<Float>, _ v2: SIMD3<Float>,
                                _ contact: inout SIMD3<Float>) -> Bool {
        let closest = closestPointOnTriangle(c, v0, v1, v2)
        guard simd_length_squared(closest - c) <= r * r else { return false }
        contact = closest
        return true
    }

    /// 点到三角形最近点（Ericson, Real-Time Collision Detection §5.1.5）。
    private func closestPointOnTriangle(_ p: SIMD3<Float>,
                                        _ a: SIMD3<Float>, _ b: SIMD3<Float>, _ c: SIMD3<Float>) -> SIMD3<Float> {
        let ab = b - a
        let ac = c - a
        let ap = p - a
        let d1 = simd_dot(ab, ap)
        let d2 = simd_dot(ac, ap)
        if d1 <= 0 && d2 <= 0 { return a }

        let bp = p - b
        let d3 = simd_dot(ab, bp)
        let d4 = simd_dot(ac, bp)
        if d3 >= 0 && d4 <= d3 { return b }

        let vc = d1 * d4 - d3 * d2
        if vc <= 0 && d1 >= 0 && d3 <= 0 {
            let denom = d1 - d3
            return abs(denom) < epsilon ? a : a + ab * (d1 / denom)
        }

        let cp = p - c
        let d5 = simd_dot(ab, cp)
        let d6 = simd_dot(ac, cp)
        if d6 >= 0 && d5 <= d6 { return c }

        let vb = d5 * d2 - d1 * d6
        if vb <= 0 && d2 >= 0 && d6 <= 0 {
            let denom = d2 - d6
            return abs(denom) < epsilon ? a : a + ac * (d2 / denom)
        }

        let va = d3 * d6 - d5 * d4
        if va <= 0 && (d4 - d3) >= 0 && (d5 - d6) >= 0 {
            let denom = (d4 - d3) + (d5 - d6)
            return abs(denom) < epsilon ? b : b + (c - b) * ((d4 - d3) / denom)
        }

        let sum = va + vb + vc
        if abs(sum) < epsilon { return a }
        let denom = 1 / sum
        let v = vb * denom
        let w = vc * denom
        return a + ab * v + ac * w
    }

    // MARK: 球 × AABB

    /// 球-AABB 相交：AABB 上最接近球心的点（clamp）。
    private func sphereAABB(_ c: SIMD3<Float>, _ r: Float,
                            _ mn: SIMD3<Float>, _ mx: SIMD3<Float>,
                            _ contact: inout SIMD3<Float>) -> Bool {
        let closest = SIMD3<Float>(
            Swift.min(Swift.max(c.x, mn.x), mx.x),
            Swift.min(Swift.max(c.y, mn.y), mx.y),
            Swift.min(Swift.max(c.z, mn.z), mx.z)
        )
        guard simd_length_squared(closest - c) <= r * r else { return false }
        contact = closest
        return true
    }

    // MARK: AABB × AABB

    /// AABB-AABB 重叠测试。
    private func aabbAABB(_ a0: SIMD3<Float>, _ a1: SIMD3<Float>,
                          _ b0: SIMD3<Float>, _ b1: SIMD3<Float>,
                          _ contact: inout SIMD3<Float>) -> Bool {
        for axis in 0..<3 {
            if a1[axis] < b0[axis] || b1[axis] < a0[axis] { return false }
        }
        // 接触点取重叠区域中心
        let lo = SIMD3<Float>(Swift.max(a0.x, b0.x), Swift.max(a0.y, b0.y), Swift.max(a0.z, b0.z))
        let hi = SIMD3<Float>(Swift.min(a1.x, b1.x), Swift.min(a1.y, b1.y), Swift.min(a1.z, b1.z))
        contact = (lo + hi) * 0.5
        return true
    }
}

    ///
    /// 退化处理（normalize 零向量兜底，任务卡要求）：
    /// - `cutDirection` 为零或与 `pt` 平行 → 换一条与 `pt` 正交的轴
    /// - `pt` 自身为零（接触点恰在球心）→ 直接取 `cutDirection`
    static func extremeAxis(pt: SIMD3<Float>, direction: SIMD3<Float>) -> SIMD3<Float> {
        let dir = safeNormalize(direction, fallback: SIMD3<Float>(0, 0, -1))

        let cross1 = simd_cross(pt, dir)
        if simd_length_squared(cross1) > 1e-12 {
            return safeNormalize(cross1, fallback: SIMD3<Float>(1, 0, 0))
        }

        // 退化 1：pt 与 dir 平行（含任一为零向量）→ 取任一条与 pt 正交的轴
        var cross2 = simd_cross(pt, SIMD3<Float>(0, 1, 0))
        if simd_length_squared(cross2) < 1e-12 {
            cross2 = simd_cross(pt, SIMD3<Float>(1, 0, 0))
        }
        if simd_length_squared(cross2) < 1e-12 {
            // 退化 2：pt == 0 → 用 dir 本身（± 对称，方向符号不影响判定）
            return dir
        }
        return safeNormalize(cross2, fallback: dir)
    }

    /// 安全归一化：零向量/近零向量返回 fallback，避免 NaN 传播到判定结果。
    static func safeNormalize(_ v: SIMD3<Float>, fallback: SIMD3<Float>) -> SIMD3<Float> {
        let len2 = simd_length_squared(v)
        guard len2 > 1e-12 else { return fallback }
        return v / len2.squareRoot()
    }

    // MARK: - 2. 截面圆 + 极值点：命中分支

    /// 锚点：FUN_00017d74 的 `|pt|² < r2 → k = sqrtf(r2 − |pt|²)` 之后
    /// `± 极值点 vs 切割半径²` 的通过分支。

    /// 手算：
    ///   被切球 center=(0,0,0) r=1；刀球 center=(1.5,0,0) r=1
    ///   coarse: d=1.5 ≤ 2 → 相交 ✓
    ///   dist2 = 2.25 ≥ r2 = 1 → 进入截面分支 ✓
    ///   contact = 被切球心朝刀方向、距离 d−r_cutter = 0.5 → (0.5, 0, 0)
    ///   |pt|² = 0.25 < 1 → k = sqrt(0.75) ≈ 0.8660
    ///   轴 = normalize(cross((0.5,0,0),(0,1,0))) = (0,0,1)
    ///   极值点 = (0.5, 0, ±0.8660)
    ///   到刀心 (1.5,0,0) 距离² = 1² + 0.75 = 1.75
    ///   cutRadius² = 2.0 → 1.75 ≤ 2 → 两个极值点均命中
    func testSectionCircleExtremesAccepted() {
        let tester = makeTester()
        let entity = makeFruit(at: .zero, radius: 1)
        let query = SliceQuery(cutter: .sphere(center: SIMD3<Float>(1.5, 0, 0), radius: 1),
                               cutDirection: SIMD3<Float>(0, 1, 0),
                               cutRadiusSquared: 2.0)

        let ev = tester.evaluate(query: query, entity: entity, radiusScale: 1)

        XCTAssertTrue(ev.gatePassed)
        XCTAssertTrue(ev.coarseHit)
        XCTAssertFalse(ev.centerInsideSphere, "dist2=2.25 ≥ r2=1")
        XCTAssertTrue(ev.hasExtremes)
        XCTAssertEqual(ev.sectionRadius, Float(0.75).squareRoot(), accuracy: 1e-4)
        XCTAssertEqual(ev.extremeA.x, 0.5, accuracy: 1e-4)
        XCTAssertEqual(abs(ev.extremeA.z), Float(0.75).squareRoot(), accuracy: 1e-4)
        XCTAssertTrue(ev.extremeAHit)
        XCTAssertTrue(ev.extremeBHit)
        XCTAssertTrue(ev.result)
    }

    // MARK: - 3. 截面圆 + 极值点：拒绝分支

    /// 同一几何，把 `cutRadiusSquared` 收紧到 1.0。

    // MARK: - 4. 近失 = 同一判定 + 半径 × 1.5

    /// 锚点：`core_logic_notes.md §1.2 步骤 7`（仅炸弹）+ T-006（0x3FC00000 = 1.5f）。
    ///
    /// 手算：
    ///   被切球 center=(0,0,0)，radius=1；刀球 center=(2.4,0,0) r=1
    ///   【1.0×】d=2.4 > 1+1 = 2 → 不相交 → false
    ///   【1.5×】r=1.5，d=2.4 ≤ 2.5 → 相交；dist2=5.76 ≥ r2=2.25 → 截面分支
    ///          contact = 朝刀方向、距离 d−r_cutter = 1.4 → (1.4, 0, 0)
    ///          |pt|² = 1.96 < 2.25 → k = sqrt(0.29) ≈ 0.5385
    ///          极值点到刀心距离² = 1² + 0.29 = 1.29

### 1. 任务卡缺陷：`slash_geometry.md` 缺失（必须回填）
- 任务卡指定「直译 `slash_geometry.md` 的切割判定公式」并「每函数注释锚定 `slash_geometry §x`」，但本轮 shared_context 中该文件为 `[缺失]`。

### 2. `contact` 语义替换（最高风险，可能整段判定语义错位）
- 原引擎 vtable+0x0C 的接触点输出落在 `local_3c/38/34`，随后按「相对球心的局部偏移」参与 `|pt|² < r²`。
- 但若 `contact` 是球面交点，则 `|pt| ≡ r`，该门恒假、截面分支永不进入——这与 T-006「截面圆 ± 极值点」结论矛盾。
- 我据此推断 `contact` 应为「刀面上最接近被切球心的点」，并按此实现。**这是推断而非直读**，需 Frida 在校验点 dump `local_3c` 核对。若原语义另有定义，`ShapeIntersect` 各函数的 `contact` 赋值需整体返工。

### 3. ± 极值点构造方向未闭合
- 反编译在 `k = sqrtf(r² − |pt|²)` 后即截断；`local_48/44/40`（`DAT_0052bfe0/e4/e8`）初值为零向量（T-007 已确认）。
- 我取 `normalize(pt × cutDirection)` 作为极值轴，退化时走正交兜底。**方向可能不是 `cutDirection` 而是刀形状法线**；由于判定取 `±` 对称，方向符号不影响结果，但「用哪个向量做叉积」会影响极值点落位。建议 Frida 补采。

### 4. 极值点判定基准待验证
- 我用「极值点到**刀中心**距离² ≤ `cutRadiusSquared`（`game+0xf0`）」。
- 另一种可能：到**刀线**的最近距离。对 sphere cutter 两种等价，对 line cutter 不等价。若原实现是按到刀线距离，line 切割的手感会不同。

### 5. `Dist2 < r²` 早退语义
- 我按反编译的位运算 `-1 < ((uint)(dist2 < r2) << 0x1f)` 还原为「`dist2 < r2` 时不做截面判定、直接命中」。
- 该位运算的符号位推演已复查两遍，但 **若 Ghidra 的 `(uint)` 转换实际是 `(int)` 语义**（对比较结果无影响，因为值为 0/1），结论不变。风险低但请复核。

### 6. `transform.radius × scale` 语义未定
- `EntityTransform.radius` 默认 1.0、`scale` 默认 25.0（`Constants.FruitDefaults`）。我按「radius 已是世界半径」处理，未乘 scale。
- 若原 `entityShape+0x14` 是「归一化半径」而实际世界半径需乘 scale，则所有球半径偏小 25 倍。**需渲染任务卡闭合缩放语义后回改**。

### 7. `SliceTesting` 协议与 `GameState` 依赖
- `SliceTester: SliceTesting` 需要 `GameState` 类型存在于同模块（`blueprint/GameState.swift`）。
- 我用注入式 `QueryProvider` 闭包绕开字段名（未臆造）。**装配层必须在 `GameServices` 构造处接线**，否则 `isSliced(game:entity:)` 会拿到空 `SliceQuery` 恒返回 false。请确认接线代码已列入后续任务卡。

### 8. 近失判定加了 `kind == .bomb` 硬保护
- 任务卡说「仅对炸弹调用」（L4），我在实现内加 `guard entity.kind == .bomb`，属**比原逻辑更严格**的约束。
- 若原逻辑是靠调用点隔离而非类型检查，这个 guard 是否会掩盖将来「炸弹以外的近失统计」需求？我的判断是 L4 明确禁止推广，保护优先。若 Kimi 认为应纯靠调用点约束，可移除。

### 9. 未实现组合
- 三角-三角、三角-AABB 返回 `false`。当前切割路径（刀 vs 实体球）不涉及，但若将来接入网格切刀会静默失效。

### 10. 120Hz 采样密度
- 轨迹超时 0.05s 在 120Hz 下等价于 6 帧，而 60Hz 下是 3 帧。原逻辑「超时写 1 点」意味着高刷新率下轨迹点数不变、但时间分辨率提升——刀光视觉长度会**变短**（同样的划动距离，采样点数量相同但时间窗更细）。渲染任务卡需评估是否要按 `dt` 累积距离而非固定时间采样。
