# T-047 代码草案说明（未修改生产文件）

建议生产路径：
- Sources/FNPBCore/Content/ContentTypes.swift
- Sources/FNPBCore/Content/OriginalContentLoader.swift
- Sources/FNPBCore/Content/WaveSpawnT047Constants.swift
- Tests/FNPBCoreTests/T047ChallengeWaveDefaultsSpawnFieldsTests.swift

本草案仅闭合：
1. FUN_00058ee4 从 defaults 复制到每个 WaveInfo 的全部已证实字段；
2. FUN_000537ec 中 Spawn 实际字段的解析；
3. defaults 作为 wave list 配置保留 globalDtStart/globalDtInc/globalDtMax，不塞入单波；
4. Spawn.posX/posY/sin/cos/radius 按整数读取；
5. override/placement 保留原始字符串同时写入已证实的数值槽；
6. Codable 往返与显式覆盖/缺省继承测试。

明确未做：
- 不修改 App/UI/挑战回合；
- 不修改 FruitMotion/BombMotion 的运动行为；
- 不猜测 placement 的运行语义；
- 不擅自把 Spawner.velocityScaleX/Y 初值从当前 0 改成 1。

Kimi 审查风险：
1. velocityScaleX/Y 初值风险：
   原 wave loader 内存块中相关轴缩放初值存在“1”的证据点，但当前 Swift 类型与历史经典测试依赖 0。
   本草案不修改该初值，仅新增字段与解析，避免改变既有运动测试。
2. override 数值语义未完全命名：
   FUN_00058528 仅证实 +0x18 缺省/其他字符串 = 1；
   "OVERRIDE_ANY" 与 "DONT_OVERRIDE" 都写 2。
   因此本草案写 overrideMode: Int32 并保留 overrideRaw，不把 2 强行命名成猜测性枚举。
3. placement 数值映射已闭合到 FUN_000531b8：
   BOTTOM=0/TOP=1/LEFT=2/RIGHT=3/LEFT_RIGHT=4，未知/空=0。
   但“未知”和“BOTTOM”数值同为 0，不能仅靠数值区分，故保留 placementRaw。
   运行语义未在本草案中实现。
4. posX/posY/sin/cos/radius 在原函数中为整数读取。
   本草案用 Int32? 表示“未出现”，避免把缺省内存位误解释成 Float。
5. WaveInfo +0xb0 的旧字段名 overridePoolID 与 defaults.overideProbabiltyPool 的关系已按 FUN_00058ee4 修正；
   旧 overrideChance(+0xe4) 未在本路径证实，保留字段仅为源码兼容。

    func testWaveAndSpawnerCodableRoundTrip() throws {
        let list = try OriginalContentLoader.loadWaves(
            from: Data(challengeLikeJSON.utf8),
            fruitIndex: fruitIndex)

        let encoder = JSONEncoder()
        let decoder = JSONDecoder()

        let waveData = try encoder.encode(list.waves[0])
        let decodedWave = try decoder.decode(WaveInfo.self, from: waveData)
        XCTAssertEqual(decodedWave, list.waves[0])

        let spawn = try XCTUnwrap(list.waves[0].spawners.first)
        let spawnData = try encoder.encode(spawn)
        let decodedSpawn = try decoder.decode(Spawner.self, from: spawnData)
        XCTAssertEqual(decodedSpawn, spawn)
